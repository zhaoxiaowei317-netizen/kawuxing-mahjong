# 孝感卡五星麻将

三人固定对局，84 张牌，16 倍封顶。采用用户逐项确认的规则版本 `xiaogan-1.0`。

An open-source three-player Xiaogan Kawuxing mahjong game, with a shared rules engine, local and online play, and reproducible AI experiments. Experimental models have not replaced the default heuristic player.

## 运行

使用 Node.js 24 或兼容版本。在项目目录运行：

```sh
npm install
npm run build
npm start
```

打开 `http://localhost:8789/`，或双击 `Play_Kawuxing.bat`。单机支持两位电脑陪打；联机由三位玩家加入同一房间并准备。底分、局数可选，人数与 16 倍封顶固定。

## 验证

```sh
npm test
npm run test:ui
```

浏览器验证默认使用本机 Microsoft Edge；也可设置 `BROWSER_CHANNEL`。`PLAYWRIGHT_MODULE` 可指定已有 Playwright 的模块文件 URL，否则使用项目开发依赖。UI 验证启动临时本地服务，数据和截图写入 `.tmp/`，不读取或修改正式房间数据。

## 结构

| 目录或文件 | 用途 |
| --- | --- |
| `src/engine.js` | 单一规则实现：计分、合法动作、状态迁移、基线电脑 |
| `core/engine.js` | 对同一规则引擎的服务端导出 |
| `core/rooms.js` | 固定三人房间、凭证、准备/恢复、联机信息遮罩 |
| `server/rooms.js` | 同一房间状态机的导出 |
| `src/app.js` / `src/online.js` | 单机、联机页面入口 |
| `src/rules.js` | 单机、联机共用规则说明 |
| `build.mjs` | 构建 `dist/` 并同步 `game/` 的运行脚本 |
| `desktop_server.js` | 默认本地服务，托管 `game/`，HTTP API 与轮询 |
| `server/index.js` | 另一服务入口，托管 `dist/`，支持 `DATA_DIR` |
| `tests/` | 规则、房间、回归及浏览器验证 |
| `ai/` | 冻结 H0、公开观测、合法动作、配对评测、重放及吞吐测量 |

旧版本未结束牌局不会套用新规则继续结算；历史战绩保留。单机旧现场保存在浏览器 `kwx-lab-legacy-v1`，联机旧房间保留并提示重开。不要删除浏览器数据或 `data/` 来升级。

游戏当前电脑仍采用向听、进张、公开可见牌与亮倒取舍的启发式策略。独立训练模块已支持 H0 模仿、PPO 自博弈、历史对手、检查点续训与模型评测，完成小规模机制验证；训练出的实验模型尚未通过高手水平或正式晋级检验。

首轮实训已完成 19,056 局训练用对局和 27,648 局评测。自身局面纠错训练在独立测试中改善了原始模仿模型；两次 PPO 对照均未证实可靠额外收益，尚无模型证实超过 H0。完整分差区间、模型哈希和后续方向见上述实训报告。

后续动作牌效模型新增 1,800 局共用训练数据、14,976 局评测。完整 16 局独立验收中，它相对同数据旧网络每百局多得 117.84 分，95% 区间 [78.96, 160.42]；相对上一轮最好纠错模型多得 101.50 分，区间 [76.69, 129.24]。相对 H0 的总体差异尚不明确，且对两家 H0 的子组仍落后，游戏默认电脑继续保留 H0。模型、分项诊断及限制见动作牌效模型实训报告。

随后完成牌效模型的普通 PPO 与模仿约束 PPO 对照：新增 9,216 局训练、7,872 局评测。跨三个种子的开发筛选仍选回原起点，没有新的晋级模型；固定诊断局面上的决策变化约为 0.7%～4.6%。178 项回归测试通过，72 份训练快照及封存测试的全部 3,840 局回放已复核。下一步应分别检验继续模仿、学习步长和牌效表达的影响。

继续模仿与步长对照另新增 9,216 手训练，连同固定候选复验共完成 43,392 手评测。大步长 PPO 第 2 个种子首批分差为正，但新批次复验相对原牌效模型为 −6.22 分/百手，95% 区间 [−25.20, 12.70]；相对 H0 为 −0.03，区间 [−15.07, 15.25]，均未确认提升。保留原研究起点和游戏默认 H0。182 项回归通过，75 份快照、首批 7,680 份完整牌谱及复验 96 份分层样本已核对；复验全部牌谱另行保存。

两步公开牌效搜索另完成 10,752 局模拟评测和 80 局事后行为诊断，没有新增神经网络训练。策略只用公开信息，比较摸牌、合法出牌后第二次摸牌的发展。开发筛选出的同向听重排策略，在新种子封闭评测中相对 H0 为 +1.24 底分/百手，95% 区间 [−15.82, 18.13]，仍未确认提升；两个对手组合的结果也不一致。保留研究策略，默认继续使用 H0。189 项回归测试通过；完整评测与复核信息见本轮报告。

公开信息终局收益推演另完成 9,792 局实际评测，没有新增神经网络训练。每次在 16 个不读取真实暗手的假设世界里比较两个出牌，按正式终局净收益筛选；新增单次前瞻对照、两种对手模型、分阶段并行与恢复汇总、赛后反事实诊断。固定候选相对 H0 为 −1.43 底分/百手，95% 区间 [−14.00, 10.42]；相对直接采用一次前瞻为 +2.93，区间 [−5.86, 11.33]，均未确认提升。197 项完整回归测试通过，默认继续保留 H0；推演与实际评测分别计数，完整复核记录见本轮报告。

成对终局收益监督实训又采集 6,000 手新训练牌局和 1,200 手独立验证牌局，从 1,344 个争议决策点生成 2,688 个成对终局分支，训练三个小网络并拟合一个线性模型。四个模型共用数据，每个网络最多 20 轮、按验证误差选轮次。3,456 局开发评测中，线性模型相对 H0 为 −4.17 底分/百手，三个小网络均为 −13.28；没有候选通过预定门槛，封闭验收未启动，游戏默认 H0。验证诊断显示三个小网络几乎直接采用所有前瞻提案，尚未学出可靠的局面筛选能力。完整回归 203 项通过；全部标签、64 份模型快照和实际评测另有完整复核，详见本轮报告。

牌面卷积与动作价值路线新增 3,600 手训练、480 手验证及 6,912 局评测，记录 73,432 个训练选择样本。已独立实现 Mortal 风格的残差牌面编码、dueling Q、蒙特卡洛收益回归、离线 CQL 和辅助顺位预测，并完成继续对战采样。离线收益模型在新种子的 16 手连续对局主指标中，相对 H0 为 +40.49 底分/百手，95% 区间 [7.68, 75.13]，成为首个在预定独立主指标上有正收益证据的学习候选。独立单局点估计 −40.63、区间 [−106.25, 25.52]；混合对手子组也未确认优势。该轮只有一个配对训练种子，仍需新批次和跨种子复验，默认 H0 保留。207 项 JavaScript 回归、2 项 Python 模型检查及并行/串行审计一致性复测通过。

牌面模型独立复验另新增 2,400 手训练、480 手验证及 15,360 局实际评测。旧模型和固定配方重训模型共用全新测试种子，分别使用完整固定预算；连续对局相对 H0 为 +6.71 与 +3.48 底分/百手，95% 区间分别为 [-18.62, 31.19] 与 [-19.40, 28.39]，均跨零。这轮未重现上一轮主指标的明确优势，也未证实固定训练流程能可靠重复该结果。旧模型辅助单局虽有正区间，不能替代预定的主要检验。全部数据和评测已逐步复核，22 份新快照核对、209 项 JavaScript 与 2 项 Python 检查通过。两个版本归档，默认 H0 保留，详见[独立复验报告](docs/reports/tile-q-confirm-2026-10-19/实验结果.md)。

亮倒取舍干预另完成 9,216 局实际评测，没有新增神经网络训练。四个开发版本只替换同一张牌的亮倒开关；按固定规则选出“H0 不亮倒”，再做全新种子连续对局验收。相对 H0 为 +39.32 底分/百手，95% 区间 [22.46, 57.13]，本批相对 H0 有正净收益证据，仍需新批次与更广对手池复验。这是取消基础策略亮倒执行的组件对照，不证明原神经网络已变强，也不证明一律不亮倒最优。完整逐局复核、29 份源码冻结检查和 212 项 JavaScript 回归通过，默认 H0 保留，详见[干预实验报告](docs/reports/reveal-study-2026-10-19/实验结果.md)。

不亮倒策略的复验与对手扩展完成 9,984 局实际评测，没有新增网络训练。固定候选在原池新种子复验中相对 H0 为 +37.43 底分/百手，95% 区间 [24.67, 50.36]，原池优势在另一批发牌中获得支持；五种扩展组合等权的次要描述为 +48.39，区间 [22.97, 73.39]。两套固定预算全部完成，结果分别报告，不把原池表现称为通用优势。52 个完整组的并行程序与原串行牌谱口径核对通过，全部逐局审计及 214 项回归检查通过。候选未被设为唯一训练教师，默认 H0 保留，详见[复验与泛化报告](docs/reports/reveal-generalization-2026-10-20/实验结果.md)。

强对手混合训练新增 4,800 手训练、576 手验证，产生 132,277 个训练选择样本，并完成 9,216 局实际评测。四种固定牌桌纳入不亮倒 H0、原 H0 与速度贪心，先模仿再做离线终局收益学习。验收门槛提高为不亮倒 H0；主要收益模型相对它为 6.64 底分/百手，95% 区间 [-5.43, 20.70]，主要收益模型本批未确认超过更强参照，没有达到提升门槛。模仿模型为次要描述（-21.66，[-38.15, -6.16]），不能替换主要检验。全部采集/评测牌谱、22 份模型快照和导出一致性已复核，216 项 JavaScript 回归通过；没有在线强化学习或自动晋级，默认 H0 保留。详见[混合训练报告](docs/reports/strong-pool-2026-10-20/实验结果.md)。
