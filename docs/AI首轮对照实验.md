# AI 首轮对照实验

本轮要回答两个问题：扩大 H0 模仿训练后，神经网络能学到多少；同一起点再做强化学习，实际净得分是否提高。它是本机 CPU 上的有界实验，不是高手模型认证。

本轮已完成，详见[三路线对照结果](reports/controlled-2026-10-17/实验结果.md)和[包含后续实验的总报告](reports/research-2026-10-18/本轮结果与下一步.md)。

## 固定实验设计

执行前把参数、代码哈希、评测选择规则写入 `manifest.json`。默认三个独立训练种子，每个种子采集 1,200 局 H0 对局，训练 64 单元隐层网络 12 遍。在第 4、8、12 遍保存模型，用另行采集的 160 局 H0 验证数据的交叉熵选择模仿起点。验证数据不进入梯度更新。

诊断同时给出全部动作准确率、排除唯一合法动作后的选择准确率，以及出牌、亮倒、胡、碰、杠、过的分项。只报总准确率会被强制动作和常见动作掩盖，且模仿准确率本身不代表实战强度。

每个种子保留三条路线：

| 路线 | 初始化 | 后续训练 |
| --- | --- | --- |
| imitation | 独立验证选出的模仿模型 | 无，作为对照 |
| self-play | 同一份模仿权重，重置 Adam | 20 轮，每轮 96 局，三家均为当前模型 |
| league | 同一份模仿权重，重置 Adam | 同样 20×96 局，25% 纯自博弈，其余由一席学习模型对两席混合对手 |

混合对手来自 H0、速度策略和近期 4 个历史模型。两条 PPO 路线使用相同训练种子、学习率 0.0001、每批 2 遍、熵系数 0.002、价值系数 0.1、批大小 128；训练回报为单局实际净分。纯自博弈会采集三席学习动作，混合桌只采集一席，因此这是**相同环境局数下的整套方案比较**，并非学习样本数、更新次数或 CPU 时间完全相等的单变量消融。实际计数都保留在各训练目录中。

## 选择与独立验收

开发评测对所有 9 个终点使用同一批发牌种子，包含 H0+H0 和 H0+速度策略两个对手组合，每组合 16 个独立单局组、2 个完整 16 局组，每组跑六种座位排列和候选/基线两臂。

先比较每条路线跨三个训练种子的完整 16 局平均得分差，选出路线；再从该路线选出开发得分最高的种子。单局得分用于同分排序。模仿对照也参与选择，避免强行挑选退步的 PPO 模型。开发样本较小，仅用来筛选；它的区间不能作为正式提升证据。

候选路径和 SHA-256 写入 `selection-frozen.json` 后，才生成封存牌局。封存随机种子在实验开始时生成并留下哈希承诺；不参与训练或模型选择。每个对手组合跑 32 个独立单局组、8 个完整 16 局组。候选分别对比 H0 和它自己的模仿起点；如果选择的就是模仿模型，则省去重复的自身对比。

预设主要指标是完整 16 局的平均净分差。两项对比的配对 bootstrap 95% 区间下界都高于 0，才支持“本次候选在本批对手与牌局上经强化学习取得提升”。这不是跨全部打法或人类段位的证明；三个训练种子也不足以充分证明训练稳定性。未通过时不切换游戏默认 AI。封存结果一旦看过就视为已消耗，以后的调参必须换新的验收批次。

每步仍检查合法动作、84 张牌守恒和零和结算。每份评测按两臂、两个测试集、两个对手组合、六个座位保存并重放 48 个审计样本；这些样本不提供给模型。

## 执行与产物

```powershell
npm run ai:experiment -- --out ai-runs/controlled-001
```

需要调整预算时，将 `ai/experiment.mjs` 中的配置字段写入 JSON，通过 `--config` 传入。输出必须是新目录。默认实验在本机运行，模型保留在 `ai-runs/`，该目录不进入 Git，也不会自动清理。

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 执行前固定的实验设计、代码版本与封存种子承诺 |
| `status.json`、`events.jsonl` | 最近状态和完整进度记录 |
| `seed-N/imitation-diagnostics.json` | 模仿学习曲线与分类诊断 |
| `seed-N/imitation-epoch-E.json` | 模仿模型快照 |
| `seed-N/self-play/`、`seed-N/league/` | 两条训练路线的检查点、优化器、历史对手、计数器 |
| `development.json` | 全部候选的开发结果 |
| `selection-frozen.json` | 封存评测前确定的候选 |
| `sealed-vs-H0.json`、`sealed-vs-imitation.json` | 独立验收的原始分组记录与统计 |
| `*-sample-replays.jsonl` | 已实际重放的分层审计样本 |
| `summary.json` | 完成状态、选定模型、统计结论、总评测局数 |
| `failure.json` | 异常信息；已经完成的模型不会被删除 |

训练中断时，可按训练指南用 `--resume` 从最近完整 PPO 检查点续训，保留原目录和历史模型。整套实验入口不自动拼接部分结果，重跑需新目录。模仿快照只保存权重和当时优化器，不能冒充完整 PPO 续训状态。

## 权重初始化与精确续训

```powershell
npm run ai:train -- --config your-ppo-config.json --initialize-from ai-runs/controlled-001/seed-0/imitation-epoch-12.json --iterations 20 --out ai-runs/new-branch
```

`--initialize-from` 是新实验：配置必须显式设置 `bcEpisodes: 0`，隐层维度一致，复制网络权重，重置 Adam 和训练计数，保留父模型路径及哈希。它可以改变学习率和对手配置。`--resume` 则必须保留原训练参数与 Adam 状态以精确延续，两者不能同时使用。

源码有更新时旧检查点可能不再满足精确续训的哈希要求；不能修改旧模型的哈希伪装成兼容版本。只加载兼容推理权重开展新实验，应使用上述明确的初始化入口。
