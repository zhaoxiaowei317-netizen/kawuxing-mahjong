# 孝感卡五星规则 v1.0

规则版本：`xiaogan-1.0`。本项目采用用户逐项确认的自定义孝感玩法。确认原文与例子见[104 条确认记录](项目现状与孝感卡五星规则基线.md)。本文件是实现与验证的规则依据；旧指南仅作为历史资料。

## 牌组、座位与庄家（第 1—12、85、90—91 条）

- 筒、条各一至九，中发白，共 21 种、84 张。无万、风、花或癞子。
- 三人固定对局，不吃，可碰、直杠、暗杠、补杠。任意对子做将。
- 首局三家等概率随机坐庄，庄家 14 张、闲家各 13 张，庄家先打，正常逆时针摸打。
- 单人胡由赢家坐庄，一炮双响由放炮者坐庄，流局原庄连庄。
- 庄家、天胡、地胡本身不另加倍。天胡、地胡仍须满足正常胡牌条件。

## 胡牌与付款（第 13—14、20—28、55—58、73、92、96—97 条）

- 普通屁胡自摸合法，两家各付 1 倍底分。点胡至少 2 倍。
- 胡牌者与付款者每有一方亮倒，该笔胡分乘 2；双方亮倒乘 4。点炮只由放炮者付自己的一份，自摸两家分别付款，可一炮双响。
- 兼容倍数相乘，每位付款者的胡分、查叫分别按 16 倍封顶，杠分另算。
- 自摸、门清本身不额外翻倍。不同拆法独立算分，取最高合法分，不跨拆法混叠。
- 无论是否亮倒，均可放弃胡牌。过胡后至本人下一次摸牌前，不能点胡或抢杠胡放过的同牌，即使倍数提高也不例外。不同牌种不受此限制。合法杠后补牌解除限制。
- 碰牌后尚未摸牌不能改报自摸；合法杠补牌自摸与庄家起手胡除外。

## 牌型（第 59—73、88—91、97 条）

| 牌型 | 因子 | 条件 |
| --- | --- | --- |
| 普通胡 | 1 | 四组顺子或刻子、杠及一对将，或合法七对结构 |
| 卡五星 | 2 | 胡到五筒或五条，并在该拆法中作为 456 中间张；允许多面听 |
| 碰碰胡 | 2 | 四组刻子或杠及一对将 |
| 明四归 | 2 | 已碰三张，最后胡到该牌第四张 |
| 暗四归 | 4 | 手中四张同牌未开杠，最后胡到第四张 |
| 清一色 | 4 | 手牌及副露全筒或全条，无字 |
| 七对 | 4 | 门闭七个不同对子 |
| 豪七对 | 8 | 七对中一组四张，算两个对子 |
| 双豪七对 | 16 | 两组四张，各算两个对子 |
| 三豪七对 | 32 | 三组四张加一对，允许胡，最终封顶 16 |
| 小三元 | 4 | 两组中发白刻子或杠，第三种作将 |
| 大三元 | 8 | 中发白三组刻子或杠 |
| 全求人 | 4 | 四组均碰或明杠，不含暗杠，单吊；自摸、点胡均算 |

## 亮倒与信息（第 15—19、47—51、57、94—95、104 条）

- 出牌后听牌可自愿亮倒，死听也允许。先按出牌前状态检查避炮，合法宣告出牌后立即生效；宣告牌被胡也计亮倒倍数。
- 未亮倒且有安全牌时，不能打任何亮倒对手的听口；全手危险才可打危险牌。
- 已亮倒正常只能摸切，即使摸到对方危险牌；不能改听、换牌、重新亮倒或碰牌。仍可过胡。
- 亮倒后符合条件的杠须保持完整听口集合不变。
- 可杠而不改变听口的暗坎盖住，其余约定手牌公开；暗杠完成后具体牌面公开。
- 自己亮倒不获得对手暗手的查看权。机器人与联机玩家仅使用本人手牌和允许公开的信息。

## 杠、抢杠与机会（第 29—54、84、93、96、98—103 条）

- 直杠由放杠者付 2 倍；暗杠两家各付 2 倍；补杠两家各付 1 倍。亮倒不增加杠分。
- 连续第 n 杠的本次杠分是该类型原值乘 `2^(n−1)`；杠开、紧接着的杠上炮、抢本次补杠的胡分因子分别为 `2^n`。
- 杠后弃牌被另一家立即直杠，连杠次数延续；被碰或开始普通摸牌则中断。
- 补杠有抢胡响应阶段，允许双响；被抢后本次杠取消、不产生本次费用，原先完成的杠分保留。禁止向已亮倒对手的听牌张补杠，暗杠不允许抢胡。胡牌优先于碰和直杠。
- 持三张同牌却选择碰而放弃直杠，该组永久不能补杠。后来摸到第四张的补杠机会仅在本次出牌回合有效，可先开其他杠再补；出牌后不能留到以后。未亮倒时暗杠可以延后。
- 过碰后至本人下一次摸牌前，不能再碰放过的同牌；杠后补牌解除。
- 正常摸墙头，杠补摸墙尾，共用同一剩余牌墙。不预留固定尾牌，无牌可补即禁止任何杠。全桌累计四杠不提前流局。
- 合法完成的杠先记流水，局末统一结算；之后放炮、流局都不取消。

## 海底、流局与查叫（第 74—83、99—101 条）

- 摸最后一张自摸乘 2，牌墙空后弃牌被胡也乘 2，包括后来碰牌后的弃牌。
- 最后一张杠补牌自摸，同时计算杠开与海底；紧接着弃牌被胡，同时计算杠上炮与海底。全部加成仍在每家 16 倍封顶内。
- 牌墙空后仍可碰、胡，碰后继续打牌，最终无人胡或碰时流局。
- 按手牌结构认听，普通 1 倍听牌、所有听口已用尽的死听都计听。
- 有人未听：每个未听者向每位听牌者赔其全部听口的最高牌值，收款者已亮倒先乘 2，每笔封顶 16。
- 三家全听：每位亮倒者向每位未亮倒者赔收款者最高牌值乘 2，每笔封顶 16。全亮、全未亮或全未听时不产生查叫赔付。
- 查叫不虚构杠开、杠上炮、抢杠或海底事件；已完成杠分仍另结。

## 版本与存档

底分默认 1，可按开桌配置缩放；局数沿用现有 16、24、32 局设置，不改变上述规则。无额外开局附加分选项。

旧版未结束牌局不混用新规则继续结算：联机旧房间保留历史并提示重开，单机旧现场另存本地备份后开新牌局，已结算记录保留。游戏默认电脑仍为按公开信息决策的启发式基线；独立试训模型经评测通过后再考虑替换。
