# 规则实施与验证清单

依据：[正式规则 v1.0](孝感卡五星正式规则.md)，对应原始第 1—104 条确认记录。

| 范围 | 本次实施 | 验证重点 |
| --- | --- | --- |
| 规则入口 | 单机、两种服务端入口共用 `src/engine.js`；固定版本、三人、16倍 | 入口一致、配置不能绕过封顶 |
| 庄家与轮次 | 首局随机；固定三人；赢家庄、双响放炮庄、流局连庄 | 可复现随机源、座位不轮换 |
| 基础胡分 | 普通自摸1倍；按付款双方亮倒逐笔乘；点胡门槛2 | 两家分别付款与每笔16封顶 |
| 牌型 | 第四张胡牌才四归、全求人含碰碰胡、开放三豪七对 | 不同拆法不混叠、四张计两对向听 |
| 连杠 | 记录次数、跨人接杠、递增杠钱及胡分 | 第三次以上、碰或正常摸牌中断 |
| 抢补杠 | 申请、响应、完成或取消；双响 | 保留此前杠钱、本次被抢无费用、牌守恒 |
| 过手限制 | 过胡、过碰同牌锁定；本人摸牌解除 | 抢杠不绕过；补牌解除；可过胡 |
| 补杠机会 | 同次出牌回合有效，可先杠别牌；放弃后禁补 | 保存恢复；非法动作不改状态 |
| 自摸动作 | 必须本人合法摸牌/庄家起手 | 碰后不能改报自摸、后端验证 |
| 亮倒与海底 | 既定安全牌限制、死听亮倒、立即生效、海底叠乘 | 宣告不能绕过避炮；无牌可补禁杠 |
| 隐藏信息 | 联机独立遮罩，机器人与预览同源可见牌统计 | 本人亮倒后仍隐藏对手；暗坎保密 |
| 客户端与存档 | 设置及说明统一；旧局隔离、历史保留 | 单机/联机 UI；运行包同步 |

以上项目已完成本轮实施。初始调研文件中的“待实现”是确认时状态，不代表本次实施后的最终状态。

## 验证结果（2026-10-17）

- `npm run build`：成功，`dist/app.js`、`dist/online.js` 与 `game/` 内对应运行包逐字节一致。
- `npm test`：97 项通过，0 项失败。新增确认规则、存档迁移及信息保密回归；原测试按新规则更新，并固定测试庄家以消除首局随机带来的偶发失败。
- 其中 100 局使用可复现随机源的完整电脑对局，逐动作检查总计 84 张、每种恰好 4 张；所有对局结束且积分零和。
- `npm run test:ui` 对应浏览器脚本通过：单机普通自摸两家各付 1 倍；旧现场备份；人数与封顶设置固定；三个独立客户端建房、准备、刷新恢复；共用规则弹窗；手机与桌面截图；真实 HTTP 抢补杠结算。
- 浏览器使用已有 Playwright 与本机 Edge 在无界面模式运行。沙箱内 Edge 无法启动，最终在获准的沙箱外测试环境完成，使用 `.tmp/rules-ui-5FN5cc` 的临时数据，未读取或修改正式 `data/rooms.json`。
- 旧存档备份失败或读取失败时禁止覆盖原存档，已增加回归测试。
- `git diff --check` 通过。未开始神经网络训练；当前电脑仍为启发式基线。测试覆盖已列场景，不代表所有规则组合均已穷举。

## 入口与使用

当前规则统一在 `src/engine.js`；`core/engine.js` 重导出同一实现。两种服务端入口共用 `core/rooms.js`。

运行中的旧服务需重启、页面需刷新，才会载入新的服务端逻辑与运行包。旧版未结束牌局不按新规则续打，已结算历史保留。以后新增规则应同时更新正式规则、对应回归用例及共用界面说明。
