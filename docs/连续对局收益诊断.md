# 连续对局收益诊断

这是多牌墙考试进行期间的探索性诊断，不改变已冻结的 83 项训练来源、92 项后续筛选方案或任何考试预算。没有新增训练采集或强度对局，也没有部署新策略。

## 论文启发与本项目目标

Suphx 的全局奖励预测器用多轮信息预测整场最终回报，再以相邻预测的变化提供单轮训练信号；原文采用序列模型，目标涉及日麻整场顺位。[Suphx 原论文第 3.2 节](https://arxiv.org/html/2003.13590v1#S3.SS2)

本项目主目标是长期净底分，不能直接移用“领先时保名次”的奖励。当前收益学习标签仅为本手两种弃牌的终局净分差，而正式考场连续运行 16 手；两动作若改变下一手庄家，未来收益也可能变化。这个差异值得量化，但不能因论文采用长期预测，就预先认定它是当前训练的主要问题。

## 小型辅助预测器

使用本轮 5,760 手训练主轨迹、360 个完整会话，拟合一个两状态近似模型：下手是否本人坐庄。输入不含对手暗手、未来牌墙或对手策略编号。

从训练数据估计两种庄家状态下的本手平均净分和下一手庄家状态转移频率；转移加固定伪计数 1。设 `μ` 为平均单手净分、`T` 为转移矩阵，则未来 `h` 手的近似净分按下式计算：

`V₀ = 0`

`Vₕ(s) = μ(s) + Σₜ T(s,t) Vₕ₋₁(t)`

这样可以在离线分支标签中检查：本手净分差加上 `V(备选后庄家) − V(原弃牌后庄家)` 是否明显改变信号。只加未来部分，不重复加本手净分或已结算杠分。会话末尾剩余手数为零，修正严格为零。

它只是冻结 Short 策略、固定对手混合下的粗略近似，忽略手牌质量、历史、对手风格及累计分影响，不是实际状态的精确马尔可夫模型，也不是 Suphx 复现。

## 本次描述性结果

864 手验证属于 54 个独立连续会话，手数和各时点的未来目标互相相关，不能当作 864 个独立样本。

| 预测未来剩余净分 | 验证均方误差（底分平方） |
| --- | ---: |
| 总预测为零 | 70.9618 |
| 训练全局均值 × 剩余手数 | 64.3578 |
| 两状态庄家模型 | 64.2653 |

相对训练全局均值基线的误差点估计只降低约 0.14%，未作独立显著性主张。参数仅由训练集估计。

将该模型仅用于原有八牌墙分支的离线诊断：训练 2,824 个局面平均绝对修正约 0.0171 底分，验证 410 个局面约 0.0183 底分；分别有 64 和 9 个局面的平均收益符号变化，零算单独符号。末手修正恒为零。

在这套很粗的模型里，庄家修正较小，当前不据此新增复杂长期预测网络或改动训练标签。它也不能排除更完整的长期建模有效；需要更好的状态描述和独立实验。相比之下，当前首次分歧集中在较早弃牌、收益信号较弱的现象更值得优先设计新采样。

实现为 `ai/dealer-value/{model,pilot}.mjs`，边界与不重复奖励测试位于 `ai/dealer-value/model.test.mjs`。完整探索输出 `.tmp/dealer-value-pilot.json` 固定源码、数据和父计划哈希。数据读取时核对已冻结训练快照；采集的完整关闭缓存重算仍随父实验审计完成。该诊断不会用于重新选择本轮模型、阈值或主指标。
