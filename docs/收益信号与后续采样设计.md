# 收益信号与后续采样设计

本记录写于 2026-10-23 多牌墙模型刚冻结、独立考试尚未完成时。这里分析的局面分类只读取新实验训练数据，不读取验证或考试；当前 83 项与后续 92 项冻结方法、模型选择和预算均不因此改变。

## 训练数据暴露的问题

多牌墙实验 5,760 手训练主轨迹中有 2,824 个首次弃牌分歧。每个局面保留实际完整手牌，对两种弃牌在原牌墙及七种重洗未来牌墙下配对续打，共 42,360 条额外终局分支。

- 2,510 个局面发生在剩余至少 29 张牌时，占有效训练局面的约 88.9%。当前“每手只取第一次分歧”的设计主要在较早的弃牌中学习。
- 单次结果与八次平均结果的符号有 1,669 个不同，约 59.1%；零作为单独符号。单次结果为零的 1,824 个局面中，平均后有 1,342 个非零。这显示一次续打经常遮住小的收益差，也不等于平均后就知道了正确答案。
- 全部训练局面的平均备选收益差只有约 0.0085 底分/局面。映射回训练主轨迹的一次分支诊断约为 +0.42 底分/百手；它不是 Always 的独立连续实战成绩。
- 按局面内重复续打方差作描述性分解，平均标签中仍有较大未来牌墙噪声；对手暗手仍是固定的一份实际样本，进一步限制可由公共信息预测的部分。

各分类均是未经多重比较校正的训练内探索。尤其少样本子组不能写成新规则；例如“向听变差”组只有 5 个局面，均值正向不能支持主动做差牌型。公开进张增加也不自动等于真实期望收益增加。

实现和原始记录：`ai/wall-average/diagnose-training.mjs`、`.tmp/wall-average-training-exploration.json`。结果固定数据文件、计划和诊断源码哈希；它不属于原有 83 项首手前冻结来源，不冒充预注册分析。

## 下一轮优先解决什么

继续单纯加大网络或训练轮数，无法单独解决目标收益差很小和早期续打噪声大的问题。先完成已经冻结的两个实验，保留其独立考试结论，再按新计划比较以下方向：

1. **从强基线出发。** 当前 Short 网络不是已确认超过 N 的策略。后续可以用已独立复验的 N 作为基础，只学习何时值得偏离它；若没有学到可靠收益，明确退回 N，而不是从较弱的基础策略开始。
2. **覆盖更有决定性的局面。** 预先固定仅在接近听牌、出现对手亮倒或牌墙较短时触发的公开条件，比较关键阶段的首次干预。触发条件只看当时允许的信息，不能用终局输赢挑样本。需要新采集及新考试，不能用本轮训练子组均值直接挑规则。
3. **增加每个局面的动作覆盖。** 当前只有 Short 与 Long 两张候选。后续可固定最多四个合法弃牌：基础策略、固定网络提议、公开牌效/番值提议，再用确定顺序补齐；相同后续牌墙比较所有候选，学习相对基础策略的收益。这样有机会发现两个旧网络都未选中的好牌。
4. **控制模拟与统计单位。** 在同一真实手牌下比较多动作、多牌墙，继续区分训练主轨迹、有效局面和额外分支。多个动作标签相关，拟合时可按局面等权；统计强度仍靠全新完整组考试。
5. **使用已核验的速度优化扩大有效数据。** 可选牌型缓存的端到端技术吞吐中位提高约 44.2%。正式使用前须把所有镜像、缓存容量和数值后端写入新来源清单，关闭缓存并用原实现完整重算。不能为了速度跳过信息边界或规则核验。

这些是由训练信号诊断支持的后续实验方向，尚未实现为新强策略。任何组合必须作为新参赛者独立验收，不能把若干组件各自的正分差相加声称整体增强。当前默认游戏 AI 仍为 H0。
