# 不亮倒策略的独立复验与对手扩展

上一轮取消 H0 亮倒执行的固定候选在新种子连续对局中，相对 H0 为 +39.32 底分/百手，95% 配对组区间 [22.46, 57.13]。这是特定对手池的一批正结果，不代表永不亮倒在全部局面、对手或规则下最优。本轮固定该候选，不再做开发筛选，不新增神经网络训练。

## 两套固定考场

**唯一主要检验：原对手池复验。** 使用全新发牌种子，保持上一轮的 H0/H0、H0/速度贪心两种组合，每组合 16 个种子组。只有连续净底分差的完整 95% 配对组区间高于零，才称本批复验支持相对 H0 的正收益。

**次要描述：扩展对手池。** 五种组合固定等权，各 4 个种子组：

| 组合 | 用途 |
| --- | --- |
| 不亮倒 / H0 | 一家不亮倒、另一家使用原亮倒逻辑 |
| 不亮倒 / 速度贪心 | 两种均不亮倒、但出牌方式不同的对手 |
| 不亮倒 / 不亮倒 | 检查对手都不亮倒时的表现 |
| 选择性亮倒 / H0 | 选择性对手保留 H0 出牌，用冻结旧 Q 比较亮倒开关 |
| 神经网络 / H0 | 冻结旧 Q 原版完整决策，与简单规则对手不同 |

所有对手沿用已实现、冻结的策略，不为本轮结果调整阈值。它们代表不同风格，未被预先认定为高手。扩展池整体和各子组未经多重比较校正，只作描述；不能用其中最好的组合替换主要检验，也不能把两个池合并后宣称普遍更强。

候选始终是同一个 h0-never：先让 H0 决定动作种类与牌张，仅在该牌有普通/亮倒合法双动作时取消亮倒。这个干预仍保留了 H0 原本考虑亮倒的弃牌排序，不是重新优化出来的最佳不亮倒策略。

## 预算与统计单位

每个完整种子组包含六种座位排列、候选/H0 两条轨迹、每条连续 16 手，即 `6 × 2 × 16 = 192` 局实际评测。保留真实轮庄和累计分。

- 原池：2 组合 × 16 组 × 192 局 = **6,144 局**，候选 3,072 手，32 个配对组。
- 扩展池：5 组合 × 4 组 × 192 局 = **3,840 局**，候选 1,920 手，20 个配对组。
- 合计 **9,984 局**，52 个完整组，没有新增训练或验证牌局。

两个池使用不同的新种子根。各池内对手组合等权，组内六种座位与连续牌局不能当成独立样本；完整配对组 bootstrap 5,000 次。两套预算均完整运行，不因前半段结果好坏取消后半段，不追加牌局争取显著性。默认电脑仍为 H0。

在“不亮倒/不亮倒”组合里，候选轨迹三家使用同一策略，轮换座位后的目标净分平均为零是零和对称性结果；真正比较的是把其中目标玩家换成 H0 后的差值，不能仅凭自博弈零分评判强弱。

## 按完整组并行

本轮把一个完整种子组作为一个任务，最多四个本地进程并行。原 `kwx-paired-v1` 的发牌种子、策略种子、座位排列和连续轮庄口径保持。合并时按原固定组合及组号排序，再计算统计，不按完成先后排序。不会把一组拆成独立统计样本。

小规模集成检查逐项比较新并行程序与原串行考场的完整牌谱、结算记录及 bootstrap 结果，另核对两套池、全部动作与连续状态的复算，并验证篡改汇总分数会被审计拒绝。

```powershell
node ai/reveal-generalization/study.mjs ai-runs/reveal-generalization-20261020 ai-runs/reveal-study-20261019
node ai/reveal-generalization/verify.mjs ai-runs/reveal-generalization-20261020
node --test tests/ai-reveal-generalization.test.mjs
```

计划在第一手发牌前写入，保存旧实验来源、候选和 Q 对手模型哈希、33 份核心与驱动源码哈希、预算及全部新种子。已有目录拒绝覆盖。逐组保存牌谱，审计从种子重发并检查每次策略动作、策略种子、轮庄、所有收益/行为汇总、顺位统计与最终分组区间。

若只在原池保持优势，候选应视为有适用对手的研究策略，不能直接变成唯一训练教师。扩展池暴露的薄弱组合应进入后续数据与对手设计；本轮不根据这些验收结果即时训练或修改策略。
