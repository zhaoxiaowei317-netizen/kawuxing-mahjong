# 持续训练进度快照

这是 2026-10-23 多牌墙实验完成 23,040 场考试、完整审计刚启动时的快照。最新进度以本页末尾的自动任务状态和最终归档报告为准。

目前结论：**模型确实完成了新训练，但尚未确认牌技提高，默认 AI 保持 H0。**

## 本批完成的实际工作

- 新采集 5,760 手训练、864 手独立验证；形成 2,824 个训练局面和 410 个验证局面。
- 每个局面比较 8 种未来牌墙，两种出牌配对续打；共增加 48,510 条终局分支。它们不是额外 48,510 手独立训练数据。
- 平均收益模型、单次收益模型各训练 16 轮、368 次更新，合计 736 次更新；分别选择第 4 轮、第 0 轮。
- 完成固定 48 个完整组、23,040 场实际新发牌考试。

平均版在共同平均收益验证标签上的误差比零预测低约 1.1%，改善很小，不能当作牌技增强。单次版选中第 0 轮，严格同策略于 Short；额外逐一核对 4,608 对完整牌谱、全部分组指标和选择计数均一致。

## 后续任务已经启动

1. 当前一次性任务正在关闭缓存重算全部采集、额外分支、34 份模型与 Adam 快照，以及全部 23,040 场考试，再生成归档报告。
2. 另一个一次性任务等待上述审计和归档完成，再复用训练/验证数据拟合 63 维公开教师分歧特征的收益判断器。
3. 判断器固定六个岭回归正则值，加零预测和训练均值常数，按验证误差选模型。若选中严格恒定策略，证明身份后停止重复考试；否则完成另一批固定 23,040 场新考试及完整审计。

这条后续路线不增加采集手数，不读取旧考试牌谱作训练数据，不自动部署策略。它已经通过完整小规模流程、原评测器四项对照、篡改拒绝和导出测试，尚无正式实战成绩。

## 已核验的速度成果

独立的牌型缓存试验在三次完整采集中，中位吞吐提高约 44.2%，对应本次耗时减少约 30.7%。原实现与优化实现的完整主轨迹和分支一致，关闭缓存、容量 1 和正常缓存全部重算也一致。正式多牌墙实验仍使用冻结的原实现。详见[吞吐核验报告](reports/simulator-throughput-2026-10-23/结果.md)。

主回归 242 项通过；速度模块另有 4 项专项、收益判断器 3 项专项、庄家价值诊断 2 项专项通过。探索性庄家预测仅用于检查训练目标，没有改动当前模型或新增牌技结论。
