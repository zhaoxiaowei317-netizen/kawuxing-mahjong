# 亮倒取舍干预实验结果

固定干预在本批独立连续对局验收中得到相对 H0 的正净收益证据。

本轮没有新增神经网络训练。涉及 Q 的版本使用同一份冻结旧模型（b9a45d031042a107…）；“H0 不亮倒”不使用神经网络推理。四个版本分别完成固定开发预算，随后仅对一个固定候选做全新种子封闭验收，合计 9216 局实际评测。游戏默认仍为 H0。

## 本轮问题与干预

上轮旧模型比重训模型更少亮倒，但净收益优势未稳定复现。本轮保留基础策略的动作种类和所选牌张，只在该牌同时有普通/亮倒合法动作时替换开关。没有改变规则引擎，也没有输入对手暗手或真实牌墙。

| 版本 | 基础出牌与其他动作 | 亮倒开关 |
| --- | --- | --- |
| h0-never | H0 | 取消亮倒执行，保留原本考虑亮倒的弃牌排序 |
| h0-q-gate | H0 | 用完整合法输入的 Q 值比较该牌的两个动作 |
| q-h0-gate | 原版 Q | H0 只比较 Q 已选定的那张牌 |
| q-reference | 原版 Q | 保持原版，作为开发参考 |

改变亮倒会影响后续牌流、轮庄和其他玩家反应。这里比较整个组件替换后的策略收益，不能据此把原模型全部优势归因于某一个孤立动作。方法、预算和停止规则见[实验方案](../../亮倒取舍干预实验.md)。

开发每种对手组合 2 个完整种子组，每组 16 手、六种座位排列；H0/H0 与 H0/greedy-speed 等权。四版 H0 对照完全相同，重复计算不增加独立起手数量。开发组很少，上表区间只作方向描述，未经多重比较校正。

固定选择：H0 不亮倒。只在三个干预中按开发净收益最高且严格为正选择，打平按预定顺序；原版 Q 不参与重新选冠军。

## 规则相关的事后解释

[正式规则](../../孝感卡五星正式规则.md)规定：未亮倒且有安全牌时必须避开亮倒对手的听口；已亮倒正常只能摸切，即使摸到危险牌。本轮未改变这些规则。保留不亮倒状态也保留了更多出牌与避炮空间。

封闭候选放炮 28 次，H0 对照 436 次；对照中 420 次发生在自身已亮倒时，16 次发生在未亮倒时。
这与上述机制相符，但属于事后描述，未分离“避炮空间”对总分提升的精确贡献。它不证明所有局面都应不亮倒，也不能把原 Q 模型全部成绩归因于亮倒频率。

行为比例有助于理解策略，不单独证明因果或牌技。开发中取消/替换开关的整条轨迹差异可以提供方向诊断；封闭主要检验只针对固定候选相对 H0，不是三个干预分别通过的因果证明。

## 复核与归档

全部 9216 局已从种子重新发牌，核对双方策略每次动作、连续轮庄、结算、亮倒/胡牌/放炮等行为字段、分组净收益与 bootstrap 统计。合法同牌双动作开关、原始 Q 掩码及不改变出牌种类/牌张的约束有集成检查。完整 JavaScript 回归 212 项通过。

旧规则、H0 与旧模型的核心源码哈希保持；本轮新干预、编排、审计源码同样在发牌前冻结。模型权重与原 Adam 断点一并保留，但没有更新权重。

完整运行目录：`ai-runs\reveal-study-20261019`。报告目录保存计划、结果、审计与前 12 个公开干预案例、模型、断点、测试日志、来源哈希和源码归档；完整牌谱保存在本机忽略目录。
