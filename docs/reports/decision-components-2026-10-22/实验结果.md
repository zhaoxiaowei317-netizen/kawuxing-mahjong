# 长短训练模型决策组件对照结果

经三项比较校正，本批检出部分单组件替换的收益方向；适用范围是另外两层保持短版的混合策略，不能直接分解长版整体分差。

冻结短版第 8 轮和长版第 26 轮，新增训练、验证和优化更新均为 0。五种策略完成 23040 局新牌局，每策略 4608 手、48 个完整组。默认 H0。

## 三项主要组件比较

短版分为动作控制器、亮倒标志和弃牌牌张三层。tile 只替换牌张层，reveal 只替换亮倒层，other 只替换动作控制器，其余两层始终使用短版。两个全同源组合精确重现原短版和长版。全部从完整合法 Q 中选择，未重新用受限掩码计算网络。参见[预定方法](../../长短训练模型决策组件对照.md)。

三种对手组合等权，每组合 16 组，每组六种座位、五条策略轨迹、连续轮庄 16 手。完整组 bootstrap 5000 次；三项共用每次分层组索引，Bonferroni 双侧 98.333333% 区间，检验族 alpha 0.05。下表使用校正区间，不用普通 95% 区间替换主要判断。

| 单组件替换减短版 | 净底分差/百手 | 98.333333% 校正区间 | 结果 |
| --- | ---: | --- | --- |
| 弃牌牌张 | 6.05 | [-3.73, 15.46] | inconclusive |
| 亮倒层 | -0.37 | [-1.30, 0.35] | inconclusive |
| 动作控制器 | -1.39 | [-2.98, -0.28] | negative |

经三项比较校正，本批检出部分单组件替换的收益方向；适用范围是另外两层保持短版的混合策略，不能直接分解长版整体分差。

同期长版减短版为 5.86 底分/百手，普通 95% 区间 [-2.17, 13.80]，仅作次要描述。没有将它与上一轮不同发牌相减或事后合并。

## 判断边界

本轮没有完整八组合因子实验，三个组件效应不能相加解释长版总损失，也不估计交互。其他两层固定短版时的结果，不能直接外推到长版环境。早期动作改变会带动后续局面改变，完整策略分差不是每次动作的独立价值。

亮倒标志变化后，合法牌张集合可能改变，因此 reveal 也可能打出不同牌张；不能称为保持牌张不变的纯亮倒试验。other 包含打牌/胡/碰/杠/过的控制及非弃牌内部选择，不把其效果单独归给某一种杠。

五条策略没有不亮倒 H0 的目标参照。本轮不宣布强度超过它、不自动选择最好混合版、不晋级或部署。相同短版控制被多个对照共用，不是三份独立复验。

## 动作控制器变化分类（事后描述）

主要结果出来后，另用冻结短版逐局检查 other 策略到达的相同公开局面。共 45660 次多合法动作选择，实际不同 23 次；每组选择数、变化数和有胡未选胡计数均与原组记录匹配，初始状态和终局结算也一致。程序和结果另存来源哈希，不属于事前冻结的主要检验。

| 同一公开局面的短版选择 → 混合版实际选择 | 次数 |
| --- | ---: |
| hu → ming | 1 |
| hu → an | 5 |
| an → discard | 7 |
| discard → an | 3 |
| peng → ming | 6 |
| ming → pass | 1 |

hu=胡，peng=碰，ming=明杠，an=暗杠，bu=补杠，pass=过，discard=弃牌。上述比较只记录选择发生了什么变化，没有给替代动作逐次计算反事实终局收益。变化来自相关的整组轨迹，不当作独立统计样本；也不能据此判断每次未选胡都错误，或把组件净损失全部归因于某一种变化。后续如检验特定胡/碰杠取舍，须重新固定方案、使用新牌局；这些已公开考卷不拿来训练。

## 完整核验与后续

全部 23040 局已关闭公开输入缓存，从种子重发并重新计算网络选择，逐动作、连续轮庄、组件计数、结算与完整牌谱均匹配。冻结模型/PT、源码、组汇总和三个校正区间已核对。234 项回归通过，涵盖双亲精确重现、单组件合法语义、缓存隐私和开关一致、多重比较以及篡改拒绝。

后续可围绕已检出的条件组件效应，预先固定候选并另做独立强度验收；不根据本批分数直接晋级，也不能推定同方向训练一定有效。

完整运行位于 `ai-runs\decision-components-20261022`；全部牌谱索引见 [artifacts.json](artifacts.json)。审计重放和开发夹具不计实际评测，不新增训练手数。
