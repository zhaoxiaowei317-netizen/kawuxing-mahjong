# 公开进张纠错学习对照结果

本批未通过预定的纠错学习联合门槛，不能认定这套训练已可靠改善网络牌技。

新增 4608 手共同训练牌局、576 手独立验证，训练选择样本 45750 条。两份标签共用实际轨迹，训练手数只计一次。正式评测 13824 局，三个网络各 4608 手，共 48 个完整种子组。游戏默认 H0。

## 学了什么

原网络在新采集牌局中直接出牌，目标玩家带 5% 合法动作探索；每个目标局面同时保存原网络答案和固定进张约束给出的答案。约束仅在原动作是弃牌时，在同亮倒开关、同弃牌后向听的合法牌中优先保留最多公开进张，再按原完整 Q 排序。它不读取真实牌墙，也不保证每次纠正都最优。

纠错学生学习约束答案，自模仿学生继续学习原答案。两组从同一 PT 权重出发，使用相同新局面、优化器、批次次序和固定训练预算；唯一训练标签差异为 teacherId。纯交叉熵，收益与顺位权重为零，没有把原行为的终局分数当成纠错动作的反事实收益。

两组各运行 8 轮，学习率 0.001，批大小 256，按各自固定验证答案的最低交叉熵选轮次，包含第 0 轮、同分取最早。评测时三个策略全部直接使用各自网络的完整合法动作 Q，不再调用进张约束或 H0 接管。参见[预定方法](../../公开进张纠错学习对照.md)和[规则](../../孝感卡五星正式规则.md)。

## 核验、范围和下一步

全部 5184 手共同采集牌局和 13824 局实际评测按种子重新发牌，逐条复核完整动作、轮庄、结算、两份标签、公开输入和分项汇总。核对 18 份训练快照及其 PT 哈希、最低验证轮次、两个第 0 轮与原权重一致；Python/JavaScript 导出检查通过。完整 JavaScript 回归 226 项通过。

小型集成测试还分别匹配原双版本考场的完整牌谱和记分记录，检查第三条轨迹不干扰原对照，并拒绝被篡改的来源、标签尾部和分数。审计重放、开发夹具不算额外正式样本。

这只有一个共同训练种子和固定小网络容量；验证模仿成功与实际收益改善分别判断。即使联合通过，也需要新发牌复验、跨训练种子和更广对手池检验；未通过则保留全部结果，不追加本批比赛争取显著。上一轮固定推理约束的正结果不自动证明学生训练有效。

下一步先依据两类验证局面的学习与保留情况判断问题位于纠错覆盖、旧行为保留还是分布变化，再设计下一项独立训练对照；本轮不自动晋级。
