# 成对终局收益监督训练实训结果

本轮尚未证明超过 H0，游戏默认电脑继续使用 H0。

新增 6,000 手训练牌局、1,200 手独立验证牌局，完成 3,456 局实际评测。训练数据与旧评测数据分离；同一批数据供三个小网络与一个线性模型共用。

实验在本机 CPU 上运行，所有牌局均由项目正式规则引擎生成。评测局数包含新旧版本及不同模型的配对重复，不等于相同数量的独立发牌样本。

## 这一轮在学什么

遇到 H0 和两次摸牌前瞻给出不同出牌时，在同一个实际训练局面上把两个选择分别打到正式结算，学习“换一种出牌最终多赢或少赢多少”。暗牌和牌墙只用于离线生成奖励；模型实际选牌只输入自己的牌与公开信息。模型没有得到真实暗手、牌墙或发牌种子。

每手最多改变一次出牌，后续继续使用 H0。线性模型使用 64 个公开特征；三个网络各有 8 个隐单元，初始预测严格为零。每个网络训练 20 轮，按独立验证误差选择轮次，包含第 0 轮。不同初始值和重复训练轮次不增加独立牌局数量。

零收益预测的验证均方误差为 20.91。验证收益是已采决策点上的反事实诊断，不是连续对局的实际分差。开发结果只用于选候选，不能作为提升证据。开发选择：H0（所有候选开发分差均不为正）。

四个候选都没有通过预先约定的开发门槛，因此没有启动封闭验收，也没有消耗封闭评测牌局。本批开发结果不能替代对固定候选的独立牌技结论；本轮没有晋级模型。

## 模型究竟学到了多少

验证集始终预测零收益的均方误差为 20.91；始终预测训练集平均收益 0.26 的误差为 20.63。这两个参照只帮助诊断预测能力，不是额外评测候选，也不参与本轮选择。

- ridge：验证集接受 145/221 次替代出牌，预测收益范围 [-2.53, 4.03]。
- mlp-0：验证集接受 221/221 次替代出牌，预测收益范围 [0.16, 0.49]。
- mlp-1：验证集接受 221/221 次替代出牌，预测收益范围 [0.19, 0.51]。
- mlp-2：验证集接受 221/221 次替代出牌，预测收益范围 [0.06, 0.51]。

mlp-0、mlp-1、mlp-2 在全部验证争议点都接受替代出牌，表明这批早停模型尚未体现按场景筛选的行为。预测误差略降也可能主要来自学习了整体收益倾向；应结合直接前瞻对照，不能把“网络参数变化”当作独立策略能力的证据。

## 可信度和限制

实验在首手采集前固定预算、源码和分阶段种子。所有 3456 局实际评测均保存完整牌谱并重放；独立审计还从种子重新发牌，重算轮庄、每次策略动作、净分汇总与 bootstrap 统计。
全部 1344 个已保存决策点及 2688 个终局标签分支均重新计算；64 份模型快照的权重、训练和验证选择已复核。没有决策点的采集牌局不在逐局重算范围内。

对手包含两家 H0，以及 H0 与 greedy-speed 的组合。相同发牌种子、六种座位排列和真实轮庄减少运气差异；区间按整个配对组计算。封闭对照按计划有条件启动，本轮没有候选进入该阶段。评测数据不回流训练。
输入仍为手工特征，动作只覆盖每手首次前瞻分歧；碰、杠、亮倒及之后的出牌沿用 H0。训练只有两类预设对手，独立开局采集与连续轮庄评测也存在分布差异。有限预算可能无法分辨很小的收益差；结果不能直接换算成真人段位。
