# 可胡时胡杠取舍独立对照结果

本批支持替换改善基础策略，但未确认超过强参照，联合门槛未通过。

冻结两模型，新增训练、验证与优化更新均为 0。四策略完成 36864 局全新对局，每版 9216 手，96 个完整组。默认 H0。

## 本轮仅改变一个冲突条件

base 精确复现上一轮 other=lss：长版控制动作，短版控制亮倒和弃牌。仅在短版全合法最大 Q 选胡，而 base 选明杠/暗杠/补杠时，候选返回这一个已有合法胡动作。其余选择全部保持 base，不强制短版本身不想胡的牌，也不覆盖其他胡/过/弃牌分歧。参见[预定方案](../../可胡时胡杠取舍独立对照.md)。

这是冻结模型的推理组件干预，没有新学习权重或逐状态期望收益估计。作用环境是 lss，并非整个长版 lll，不外推到所有开杠或有胡时的取舍。

## 两项预定主要检验

三种既有对手组合等权，各 32 组；每组六种座位、四条独立策略轨迹、连续轮庄 16 手。完整组 bootstrap 5000 次。下表前两项双侧 95% 区间必须同时严格大于零，才支持机制与强度联合主张（交并检验）。
