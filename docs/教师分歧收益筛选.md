# 教师分歧收益筛选

此方案和模块在多牌墙实验尚处于采集阶段、未看到其考试成绩时准备并通过小规模完整测试。它不改变正在运行的多牌墙实验，也不是已经验证有效的训练结果。以下预算在父实验审计完成前固定；新实验启动时写入带哈希的正式计划。

当前收益网络从完整牌张输入学习某个备选是否更好，需要同时识别手牌结构和收益关系。可以增加一个可解释的对照：固定 Short、Long 两个已有网络，把其公开排序分歧和公开牌效特征交给一个轻量收益判断器。两者的分数差只是排序信号，不能直接当作期望得分。

新判断器仍只决定每手第一次合格的不亮倒弃牌分歧，其余继续 Short。公开特征包括两张候选弃牌的牌效差、原弃牌的牌效、两个固定网络在完整合法动作集合上的排序分数差、剩余牌数、亮倒与副露等公开上下文，以及预设的少量交互项。对手暗手、牌墙和实际分支结果都不进入输入。

拟使用已完成并完整审计的多牌墙训练、验证数据，复用平均收益标签，不使用任何考试牌谱。因此它不会新增采集手数，也不能把同一批数据算两遍。父实验的牌张网络平均收益模型作为固定对照。

判断器用训练集均值和标准差归一化特征，固定六个岭回归正则值：0.001、0.01、0.1、1、10、100。仅比较六个拟合结果、零预测和训练均值常数；按验证收益 MSE 选择，1e-12 内同分保留较早候选。常数项不受正则惩罚，特征尺度只由训练集计算。保存全部拟合、诊断和导出，独立重跑并检查 Python/JavaScript 一致性。

正式验收使用新发牌，对比判断器、父实验 Average 网络、Short、Always、N。固定三个对手组合、每种组合 16 个完整组、六种座位、五个策略、每次连续 16 手，合计 23,040 场实际对局，每策略 4,608 场。四个进程、推理缓存 2,048，独立审计关闭缓存。三个对手组合等权，以完整配对组 bootstrap 5,000 次，报告每百手净底分差和名义 95% 区间，组内牌局不能当成独立样本。

只有同时胜过 Average、Short 和 Always，才支持公开教师分歧特征改善收益筛选；四项加上 N 对照均通过，才支持整体联合强度主张。采用交并检验，单项名义区间不能当成四项任取成功的多重比较控制。区间跨零表示证据不足，不是两策略相等。不因中途分数追加样本、改阈值、改正则值或合并旧考试，不自动部署。

每手仍只使用第一次合格的 Short 不亮倒弃牌与 Long 牌张备选分歧。判断器预测差严格大于零才接受，平手保留 Short；首次机会无论接受还是拒绝都用掉，其后继续 Short。胡、碰、杠、亮倒控制保持 Short。Average 也只在同样首次机会按其收益预测筛选；Always 总接受同一首次备选；N 为固定不亮倒规则对照。

预设停止条件：八个候选全部拟合/记录完毕后，如果所选模型的特征系数逐项恰好为零，则判断器恒定选择 Short 或 Always。先证明该全局策略身份，不执行重复考试；不能把没有考试说成与其他策略相等。如果所选模型确实依赖特征，则完成固定全部 23,040 场考试，不能中途停止。没有使用“验证接受率看起来相同”来证明全局等价。

正式启动前冻结 92 项来源：父实验 83 项，加本轮配置、特征、线性模型、策略、派生数据、分组、运行、审计与 Python 拟合器 9 项。固定父实验计划、模型、数据和完整审计文件哈希。父实验全部原始分支重算结果作为已验证依赖继承，本轮重新编码全部训练/验证根局面、逐字节核对公开特征数据，重新拟合全部候选并核对系数、归一化统计、选模、导出和 Python/JavaScript 推理；实际发生的全部新考试均关闭缓存重发和逐项核对牌谱、结算及统计。

此时已完成特征、完整训练与评测驱动、导出、审计和三项专项测试。测试包括公开输入白名单、合成已知信号、标签篡改拒绝、小规模完整数据依赖和四项原评测器对照。合成信号只能证明实现能拟合已知关系，不能证明麻将牌技提升。正式训练必须先等父实验完整审计和归档完成，且不会使用其考试牌谱作为输入。
