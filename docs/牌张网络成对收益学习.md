# 牌张网络成对收益学习

日期：2026-10-23，协议 `kwx-paired-tile-return-1`。这是新的实际训练实验，不继续扩大胡杠修正考卷。此前 64 特征、小网络的成对终局监督和牌张网络的离线绝对收益回归都曾尝试，尚未可靠超过强参照；本轮将成对差分收益用于当前牌张网络和短版自身局面，不称首次使用收益学习。

## 学习范围与新数据

冻结原短版第 8 轮、长版第 26 轮。短版全合法选择为 baseline；只有它选择不亮倒弃牌，且 ssl（短版动作控制、短版亮倒、长版牌张）给出不同合法牌张时，形成一个机会。每手仅第一次机会可干预，之后所有决策仍为短版，胡、碰、杠、亮倒均不干预。候选收益网络只决定接受还是拒绝该牌张提议，不是直接模仿长版。

首手前固定：5,760 手新训练、864 手新验证；16 手连续场次，三种既有对手组合、六种座位均衡轮换。采集完整短版轨迹，不加入探索，不读取任何旧考试牌谱训练。每手至多一个样本，未出现分歧的完整手仍计入采集并审计。

遇到第一次分歧，保留真实训练局面。实际短版后续与原手最终得分作为 baseline；从相同局面改出另一张牌，其余决策继续短版、相同对手，打到正式结算。监督目标为 `(alternative 最终净分 − baseline 最终净分) / 16`；已发生杠分在差分中抵消。额外分支单列，不算新的独立训练手数或正式评测局数。这是一个实际暗牌世界的成对实现收益，不是该公开局面的已知期望收益。

暗牌和牌墙仅用于离线生成标签和牌谱审计。训练加载器只取已审核的公开牌张编码、完整合法动作集合、两种动作 ID 和差分标签；不将真实对手暗牌、牌墙、种子或对手策略身份输入网络。

## 固定训练与选择

沿用约 2.2 万参数的残差牌张网络，初始化短版编码器，将动作输出头与 valueHead 清零；固定 valueHead、rankHead 和冗余动作偏置，训练其余参数。优化 `0.5 * (Qalternative − Qbaseline − gain)^2`，不加模仿、CQL、顺位或旧概率约束损失。Adam 学习率 0.001、批大小 128、梯度裁剪 5，固定 16 轮，按独立验证集成对均方误差最低选择，含第 0 轮、同分取最早。

第 0 轮任意合法输入的差分预测严格为零，因此所有机会均保留短版。若没有训练/验证机会则不训练；若最终选择第 0 轮，证明与短版策略严格一致，停止封闭验收，不花牌局重复检验已知相同策略。训练仍完整跑满预定轮数；这个停止条件不按考试分数决定。

训练损失、零预测误差、接受比例和验证样本上的已实现分支收益均作诊断。验证分支收益不是连续实战分差，不用它选模型或宣布牌技提升。推理严格以差分预测 `> 0` 接受提议，等于零保留短版，不调阈值。

## 封闭验收与判定

只要所选轮次大于零，固定完成三种对手各 16 组、六座位、四策略、连续轮庄 16 手，共 48 完整组、18,432 局，每版 4,608 手：learned、always（每手第一次分歧总接受提议）、baseline（原短版）、reference（不亮倒 H0）。模型在首局前冻结，发牌种子全新。

主要对照为 learned 减 baseline、learned 减 always、learned 减强参照。按对手组合等权、完整组配对 bootstrap 5,000 次，双侧 95% 区间。前两项须同时严格大于零才支持“学会有收益的条件筛选”；三项都通过才支持本批学习与强度联合主张，采用交并检验。单个座位、版本、牌局和根节点不当独立样本。各对手子组与行为分解是未经多重比较校正的描述。

不按中途成绩改数据量、轮数、阈值或模型，不合并旧考卷求显著，不把考试数据回流训练，不自动晋级。即使通过也需独立发牌及独立训练种子复验。默认 H0。
