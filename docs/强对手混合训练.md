# 把已验证的打法接入训练和验收

不亮倒 H0 已通过两批独立原池测试，扩展池整体也为正。下一步用它提高训练和验收门槛，但不把它当成所有局面的标准答案。

本轮保持原来的 21 种牌、全部合法动作、残差牌张网络、公开输入和终局净收益目标。新增的采集、实验和审计程序在 `ai/strong-pool/`，旧实验源码和模型均保留。未硬编码禁止网络亮倒，也未把模型失误交回 H0；评测全程由网络决定合法动作。

## 固定训练配置

四种牌桌按连续 16 手为单位轮换，12 个连续场次完成一次座位均衡：

| 桌型 | 三家打法 |
| --- | --- |
| 1 | 不亮倒 / 不亮倒 / 不亮倒 |
| 2 | 不亮倒 / H0 / H0 |
| 3 | 不亮倒 / 不亮倒 / H0 |
| 4 | 不亮倒 / 速度贪心 / H0 |

每个座位的教师角色占比为不亮倒 7/12、H0 4/12、速度贪心 1/12。各自给自己决策时的动作打标签，三家样本都进入训练；每次有多个合法动作时，5% 概率均匀探索。标签是探索前的教师动作。不同打法的动作标签可能冲突，这是一项明确的混合分布设计，并不保证比单一教师更好。

教师身份只用于采集，不输入网络。输入仍只含该玩家可见的牌局信息。完整回放保存私有状态供审计，训练只读取公开编码、动作、教师标签、收益和顺位。

- 4,800 手训练，576 手独立验证；四个本地采集进程，分片起点在完整场次边界。
- 模仿学习 12 轮，再以所选模仿权重开始 8 轮终局收益回归，加保守 Q、教师动作和顺位辅助损失。
- 网络和优化器沿用原紧凑 Tile-Q 配置，从新初始化开始，不使用旧考试牌局训练。
- 各阶段只按固定验证损失选检查点，包含第 0 轮，平分取较早者。两份模型在第一局评测前写入 `models.json` 冻结。
- 本轮没有在线自我采样强化学习。不能把离线收益回归写成完整的自博弈强化训练。

## 一项主要检验

预先指定离线收益模型为主要对象，与更强的 **不亮倒 H0** 比较。三种对手组合固定等权：不亮倒/H0、不亮倒/不亮倒、不亮倒/速度贪心。每组合 8 个全新种子组，每组含六种座位、两条轨迹、连续 16 手，共 4,608 局实际评测。

模仿模型也运行同样的 4,608 局，作为次要诊断；其成绩不能事后替换主要对象。两者共 9,216 局，使用相同开局和各自重跑的同一控制轨迹；重复控制不算两批独立证据。各模型有 24 个完整配对组、2,304 手候选轨迹。区间按完整组、在各组合内 bootstrap 5,000 次，组合等权。

主要模型的双侧 95% 差值区间全部大于零，才称本批支持超过不亮倒 H0。模仿模型和各子组都是未经多重比较校正的次要描述。预算全部跑完，无论中途成绩；不补局争取显著，不用考试牌局训练，不根据成绩改网络、阈值或默认电脑。

不能单凭本轮成绩把效果归因于“加入不亮倒教师”：相比旧轮次，数据量、训练分布和新随机初始化同时改变，本轮也没有同步训练旧数据配方对照。它检验的是新固定配方有没有超过更强基准。

## 执行与审计

```powershell
node --test tests/ai-strong-pool.test.mjs
node ai/strong-pool/study.mjs ai-runs/strong-pool-20261020 ai-runs/reveal-generalization-20261020
node ai/strong-pool/verify-stream.mjs ai-runs/strong-pool-20261020
```

第一手采集前保存计划、来源实验哈希、全部核心/驱动源码哈希、预算和分离种子。训练程序保持原格式；新增教师语义和驱动哈希写入数据清单，并由新审计器校验。现有目录拒绝覆盖。

数据审计从种子重发，核验每次教师/探索动作、公开输入、动作掩码、标签、结算和连续轮庄。评测审计用冻结模型从种子重发全部牌局，逐条比较完整动作、策略种子、结算、汇总和分组区间；检查全部 Python 权重/优化器哈希及 Python/JavaScript 输出一致性。测试还会主动篡改教师标签和组分数，要求审计拒绝。

默认电脑保持 H0。即使主要检验为正，仍需独立复验、更多对手和行为诊断后再讨论晋级。

`diagnose.py` 另在冻结候选后做固定验证局面的事后诊断，记录教师动作一致率、弃牌牌张/亮倒开关差异、教师胡牌而模型未胡的次数，以及收益阶段相对模仿阶段的动作变化。诊断单列源码与模型哈希，不参与选模型、训练或主要检验；教师分布中的表现也不能直接代表模型自身对局状态。

正式采集结束后发现合并训练文件解压超过 512 MiB，旧整文件审计读取器触及 V8 字符串长度上限。原 `verify.mjs` 保留冻结，新增 `verify-stream.mjs` 和 `stream-data.mjs` 逐手解析；动作、特征、收益、模型和汇总检查沿用相同条件，新增扩展哈希写入审计结果。`tests/ai-strong-pool-stream.test.mjs` 比较两版完整小型审计结果，验证 gzip 分段/分块、损坏输入和篡改计数。此修复不改变训练数据、模型、原计划或评测预算。
