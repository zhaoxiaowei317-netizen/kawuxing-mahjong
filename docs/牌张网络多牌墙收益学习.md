# 牌张网络多牌墙收益学习

本轮检验：在相同训练局面上，减少后续摸牌造成的收益标签噪声，能否提高出牌筛选模型的实战得分。方案在正式采集前固定，技术试跑不进入正式数据。沿用既有孝感卡五星规则，默认游戏策略保持 H0。

## 两个模型唯一的训练差别

固定此前的短训模型 Short（第 8 轮）和长训模型 Long（第 26 轮）。Short 使用完整合法动作排序；Long 仅提供出牌牌张的备选排序，动作种类和亮倒决定仍来自 Short。

每手最多取第一个符合条件的局面：Short 选择不亮倒的弃牌，Long 的牌张排序给出另一张合法弃牌。主轨迹继续使用 Short，不在采集时探索或改动后续牌局。

保存该局面实际完整状态，仅供离线标签计算。第 0 组使用实际剩余牌墙；第 1—7 组各用独立种子重新洗剩余牌墙。每组都从完全相同的手牌、历史、过胡过碰等状态出发，分别执行原弃牌和备选弃牌，然后继续用 Short 和固定对手打到本手结束。两分支共享该组的牌墙。第 0 组原弃牌分支复用主轨迹的实际终局。

标签为 `(备选终局净分 − 原弃牌终局净分) / 16`。Single 模型使用第 0 组标签；Average 模型使用 8 组标签的等权平均。双方使用相同公共输入、初始化、批次顺序、优化器和训练预算。不同标签值自然产生不同梯度和参数。

这只平均了**固定实际对手手牌和剩余牌张集合之下的未来摸牌顺序**。没有重新采样对手手牌，不是对公共信息下全部未知状态的精确期望。每个局面的 8 个结果不算 8 个独立训练局面；重复模拟可能得到相同牌墙或结果，仍保留。已有杠分在成对差值中抵消，不重复加分。

训练数据通过字段白名单，只保留公共编码、合法动作编号、两个动作编号和收益标签。完整手牌、牌墙及回放不进入模型输入。固定真实手牌用于离线收益标签不等于实战偷看。

## 固定预算与选模

- 新采集 5,760 手训练主轨迹、864 手验证主轨迹，每 16 手连续积分；三个对手组合与六种座位安排轮换。四个采集进程，各训练分片 1,440 手。
- 每个有效局面 8 个配对结果，除主轨迹外增加 15 条完整终局分支。没有有效局面的主轨迹也保存并审计。
- 两个模型分别初始化同一个 Short 主干，动作头和价值头清零；冻结价值头、排名头和公共动作偏置，其余 21,504 个参数训练。
- 同一 TileQ 网络，总参数 21,765。Adam 学习率 0.001、批量 128、梯度裁剪 5；双方各训练固定 16 轮。
- 目标仅为成对收益差的平方误差；不加模仿、CQL、排名或策略锚定损失。
- 每个模型按**各自标签的验证 MSE**选最小值，包括第 0 轮；误差相差不超过 1e-12 时选更早轮次。保存全部 17 组参数、Adam 状态及导出模型。
- 不直接用两种不同标签的原始 MSE 大小判断哪一个模型更强。诊断时额外在共同的平均收益验证标签上比较两个已选模型、零预测和训练均值预测；这是描述性诊断，不参与再选模。

第 0 轮预测收益差恒为零，按平手保留 Short。即便某个模型选中第 0 轮，也完成固定实战验收，保留直接对照。若训练或验证完全没有有效局面，预设停止，不执行训练和实战验收，不把没有实验当作策略等价。

## 固定实战验收

新种子独立验收，训练、验证、考试隔离。共 48 个完整组（三个对手组合各 16 组），每组包括六种座位、五个策略和每次 16 手连续积分，共 **23,040 场实际对局**，每策略 4,608 场。

五个策略分别为 Average、Single、Always、Short、N。Average/Single 在每手第一个合格机会预测差值严格大于零才接受备选；平手拒绝。Always 无条件接受同一个首次备选；Short 拒绝。首次机会无论接受或拒绝都用掉，后续全部继续 Short。N 为已固定的不亮倒强规则对照。胡、碰、杠、亮倒决定不由本轮模型直接改写。

四个预设共同主比较均为 Average 减对照：Single、Short、Always、N。每个比较按完整组进行配对重采样 5,000 次，三个对手组合等权，报告每百手净底分差和名义 95% 区间。同一组内座位、牌局、五个策略相关，不能拆成独立样本。

Average 同时优于 Single、Short、Always，才支持本轮“降低标签噪声改善筛选学习”的联合主张；四项均严格正向，才支持包括强规则对照在内的整体联合主张。采用交并检验，各比较单独的名义区间不能冒充多项任取成功的家族错误率控制。区间跨零即证据不足，不是策略相等。对手分组、行为计数、预测误差、收益标签方差均为描述性结果。

固定预算打完，不按中间分数加样本、换阈值、换轮次、重抽种子或合并以前考试。不会用考试结果训练，不自动替换游戏默认 AI。

## 可复核性

正式启动前冻结 83 项源码：此前 76 项加本轮 7 个模块。训练复用冻结的 `ai/paired-tile/train.py`，保持目标和输入白名单一致。计划固定模型和父实验文件哈希，训练与考试使用独立种子命名空间。

完整审计关闭推理缓存，从种子重发全部训练和验证主轨迹，重算全部 15 条额外终局分支，逐项比对完整回放、标签和派生训练文件。两个模型都重跑全部训练，检查每一轮参数、Adam、历史、选模和 Python/JavaScript 推理一致性；考试完整重发所有 48 组，重算全部统计结论。

预设噪声诊断报告局面内样本方差、原标签和平均标签的跨局面方差，以及估计的未来牌墙噪声贡献。对固定完整状态，均值的估计噪声项是局面内方差除以样本数；扣除噪声得到的局面间方差估计可能为负，原样报告。它不是对手未知手牌带来的全部噪声，也不是牌技提升证据。
