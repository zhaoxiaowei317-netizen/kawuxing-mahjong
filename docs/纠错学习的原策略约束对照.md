# 纠错学习的原策略约束对照

日期：2026-10-21，实验版本 `kwx-outs-anchor-1`。规则 `xiaogan-1.0`、网络结构、原始研究起点和游戏默认 H0 不变。上一轮学生学会了 453/550 个纠错答案，但也改变了 192/5,099 个无需纠错的选择；两个收益区间均跨零。这只是本轮研究线索，尚不能说这些额外变化导致了收益不确定。

本轮仅比较训练目标：普通纠错模仿与“普通纠错模仿＋原策略偏好约束”。不同时更换网络、采集行为或纠错规则，不读取实际对手暗手，不使用旧验收牌谱训练。

## 预定设置

- 从原始强对手 offline 第 8 轮（JSON SHA256 `e9374f999a3481c109a9605f3a59e1c18c5682cb6187ea38ece7105c917cac82`）初始化两组学生。不是从上一轮已训练的学生继续更新。
- 新采集 4,608 手训练、576 手验证，三种既有对手组合与六种座位等量轮换，每桌连续 16 手。实际采集者为原网络，固定 5% 目标玩家探索；只采集该玩家的多合法动作选择。复用冻结的配对标签采集器，嵌套的兼容采集协议完整写入本轮计划，新增驱动/训练器另行冻结。保存公共原始记录、自模仿标签和纠错标签，但两学生都使用同一份纠错数据。
- 普通版最小化纠错标签交叉熵 CE。约束版额外加上 `平均[无需纠错 × KL(原网络概率 || 学生概率)]`，系数固定 1，温度固定 1。两个分布都用相同公开输入、完整合法掩码，对 Q 做 softmax。需要纠错的局面不加约束。该分布只是训练偏好，不是校准过的胜率或收益概率。
- 冻结教师在 Python 中计算软目标，原始硬标签仍来自冻结 JS 采集器。允许导出精度内的近似并记下 argmax 差异，要求 JS 硬标签对应 Python Q 距最大值小于 1e-5；不根据分差调温度或系数。
- 两组同初始化权重、相同 Adam 重置、随机种子和每轮批次次序；学习率 0.001、批大小 256、裁剪 5，各 8 轮。两组都计算同一冻结教师软目标，只有约束损失的权重不同（0 对 1）；收益和顺位损失为零。
- 统一按固定验证集上的**纠错 CE**选择最低轮次，含第 0 轮，同分选最早；额外约束目标单独记录，不作为选轮次标准。禁止根据实战得分换轮次或调参。

## 验收

四条独立目标策略轨迹：约束学生、普通纠错学生、冻结原网络、不亮倒 H0。前三者都用自身完整合法动作 Q 直接出牌，没有进张约束或 H0 推理接管。第四条本身就是强启发式参照。

三种对手组合各 16 个完整组，每组六种座位排列、四个版本、真实连续轮庄 16 手，共 **18,432 局**，每个版本 4,608 手。组内各版本共享初始牌墙种子，后续轨迹独立。按对手组合等权、完整组 bootstrap 5,000 次，不能把组内手数或座位当独立样本。

联合主要主张要求：**约束学生减普通学生**和**约束学生减原网络**的完整双侧 95% 区间都严格高于零。交并检验，单项通过不能替代整体通过。约束学生减不亮倒 H0、全部对手子组、旧判断保留率和纠错采纳率均为未经多重比较校正的描述性结果；三项对照共用约束学生轨迹，不是三次独立复验。

预算和源码先冻结；无论中途输赢全部完成，不扩样求显著，不自动晋级，不与历史另一批发牌相减。单个训练种子即便通过也仍需独立发牌与跨种子复验。
