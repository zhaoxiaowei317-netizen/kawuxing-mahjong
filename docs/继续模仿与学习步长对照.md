# 继续模仿与学习步长对照

上一轮普通 PPO 和带模仿约束 PPO 没有筛选出更强候选；固定诊断局面上只有约 0.7%～4.6% 的选择发生变化。本轮检验两个问题：只继续模仿是否有帮助；增大 PPO 学习步长是否有帮助。

首批训练与验收已完成，见[对照结果](reports/bc-step-2026-10-18/实验结果.md)。选中大步长 PPO 第 2 个种子，但相对原模型和 H0 的首批区间均跨过零。固定候选后另做一次预算预先封顶的新种子复验，两批结果单独报告。

独立复验也已完成，见[复验结果](reports/bc-step-confirmation-2026-10-18/复验结果.md)。两项分差区间仍跨零，未获得晋级证据，本轮按预定预算结束。后续优先检验更深的牌效评估和公开对手风险信息，继续用固定候选、新牌局与原模型作对照。

## 三条路线

| 路线 | 训练目标 | 学习率 | 模型来源 |
| --- | --- | ---: | --- |
| ppo-low | 净收益 PPO、熵及价值损失 | 0.002 | 复用上一轮全部三个普通 PPO 终点 |
| bc-only | H0 标签交叉熵 | 0.01 | 新训练，不使用收益、优势或价值损失 |
| ppo-fast | 净收益 PPO、熵及价值损失 | 0.01 | 新训练 |

比较 bc-only 与 ppo-fast，可以在相同步长下比较训练目标；比较两条 PPO，可以比较步长。所有路线从同一个牌效模型复制权重并重置 Adam。新路线沿用对应旧 PPO 种子的训练随机种子、对局数、角色与更新配置；第一个采样轮次相同，后续随着策略变化产生不同轨迹。相同对局预算不等于相同动作样本。

默认参考实验为 `scorer-ppo-comparison-20261018`：三个种子，每个终点训练 12 轮、每轮 128 手牌。新增两条路线合计 9,216 手，复用的三个终点此前共训练 4,608 手，二者分别记账。每个新模型仍只训练 1,536 手，是本机 CPU 上的小模型对照。

BC-only 也在自己的随机策略局面上采集 H0 标签。默认 25% 三席自博弈，其余一席学习者对两席 H0；只训练学习者决策。它不按实际输赢更新，不训练价值头，不使用熵奖励。PPO 的净收益定义、两遍更新上限、批大小 128、0.5 梯度范数上限与 0.03 KL 停止阈值保持原配置。

## 选择与验收

原起点和九个终点都在一批新开发牌局评测。每个对手组合采用 8 个单局组、2 个连续 16 局组；对手为 H0+H0 和 H0+速度策略。每组跑六种座位排列及候选、对照两臂。开发连续局组数比上一轮增加一倍，但仍较少，仅用于筛选。

先比较每条路线跨三个种子的平均 16 局净分，再选胜出路线中最好的种子。独立单局得分用于同分排序；在 1e-9 容差内完全相同优先保留原起点。复用全部三个旧 PPO 终点，避免只挑旧实验表现最好的一个。

候选固定后，与 H0 和原牌效模型分别进行新封存评测：每对手组合 32 个单局组、8 个完整 16 局组。封存随机种子在训练前生成并保存哈希承诺。相对原起点的主要指标区间下界大于零，支持本次研究模型取得提升；同时相对 H0 的下界也大于零，才支持游戏晋级。若选回原模型，不重复做自身对自身评测。

开发路线之间的差异只用于筛选。最终封存只测试选中候选，因此不能用它确认全部路线的因果差异。具体结论还受小模型容量、有限训练预算和两个对手组合限制。

## 执行与恢复

```powershell
node ai/action-scorer/calibration.mjs --reference ai-runs/scorer-ppo-comparison-20261018 --out ai-runs/bc-step-new
```

可通过 `--config 配置.json` 覆盖开发和封存预算、大步长等字段。参考实验决定训练种子数、每模型训练局数及其他共同训练配置。程序检查旧模型的来源、版本、规则、父权重、训练种子及哈希；不会重新训练低步长对照。

`manifest.json` 在训练前保存设计与全部复用模型哈希；`status.json` 和 `events.jsonl` 保存进度；`seed-N/bc-only`、`seed-N/ppo-fast` 保存完整检查点与 Adam。BC-only 的程序接口 `trainBc({resume, config, iterations, out})` 支持相同配置和源码下精确恢复，恢复到新目录；PPO 使用原有 `train.mjs --resume`。整套对照不自动拼接已中断的开发评测，重跑需新目录。

默认十个开发候选共评测 9,600 手；选中原起点时总评测 13,440 手，否则为 17,280 手。所有评测保存完整压缩牌谱，并现场重放分层样本。正式房间、浏览器存档与默认游戏 AI 不随实验修改。

## 一次固定预算的独立复验

首批候选对原模型的分差为每百手 +33.98，95% 区间 [-3.32, 76.57]；对 H0 为 +23.11，区间 [-9.25, 56.65]。点估计为正，区间仍不确定，因此固定该候选，另开新种子复验一次。

复验每对手组合采用 32 个单局组、32 个连续 16 局组，bootstrap 5,000 次。分别对比 H0 与原模型，总计 26,112 手牌，新增训练为零。两项比较可以在不同进程并行执行，输入为相同固定权重和新种子。以新批次本身的两个主要区间下界判断是否支持复验，不合并前后批次追求显著，也不依据中途结果追加本次预算。

```powershell
node ai/action-scorer/confirm.mjs --mode prepare --study ai-runs/bc-step-calibration-20261018 --out ai-runs/bc-step-confirmation-new
node ai/action-scorer/confirm.mjs --mode run --out ai-runs/bc-step-confirmation-new --against H0
node ai/action-scorer/confirm.mjs --mode run --out ai-runs/bc-step-confirmation-new --against parent
node ai/action-scorer/confirm.mjs --mode finalize --out ai-runs/bc-step-confirmation-new
```

`prepare` 必须先执行，并固定全部预算、模型 SHA-256、源码、种子承诺和首批统计。每项评测的 48 份分层样本现场重放，共 96 份；每步仍检查合法性和守恒，全部完整牌谱压缩保存。本复验不声称重新播放了全部 26,112 份记录。
