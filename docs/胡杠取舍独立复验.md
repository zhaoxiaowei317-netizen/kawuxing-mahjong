## 预定统计与解释

沿用两项主要比较：候选减 base、候选减不亮倒 H0。三种对手组合等权，按完整组配对 bootstrap 5,000 次。两项双侧 95% 区间须同时严格大于零，才通过本批机制与强度联合门槛；对照共享候选轨迹，不当独立复验。
