# 公开进张纠错学习对照

本轮检验：上一轮有收益证据的固定进张约束，能否学进网络权重，并改善网络直接出牌的成绩。实验版本 `kwx-outs-distill-1`，规则 `xiaogan-1.0`，游戏默认 H0。代码在 `ai/outs-distill/`，旧训练器、网络结构、组件规则和旧报告均冻结。

## 提前固定的方法

- 起点为强对手混合训练的 offline 第 8 轮，SHA256 `e9374f999a3481c109a9605f3a59e1c18c5682cb6187ea38ece7105c917cac82`。不是初期旧权重。
- 4,608 手全新训练牌局、576 手独立验证牌局；每桌 16 手，轮换三种既有强对手组合、六种座位排列。只记录原网络所在座位的选择，其他玩家暗手不进入观测。
- 实际采集行为为原网络，只有该玩家使用固定 5% 合法动作随机探索。每个局面只计算一次原始完整合法掩码 Q，同时生成原网络答案和冻结约束纠正答案。两组数据除了 `teacherId` 外逐条相同；不混入已公开验收牌谱。
- 两个学生分别继续模仿原网络、模仿纠错答案；都从同一 PT 权重初始化，重置 Adam，同一随机种子与批次次序，学习率 0.001、批大小 256、梯度裁剪 5，固定 8 轮。纯交叉熵，顺位与收益目标权重为零。终局收益仅存档，不能当成纠错动作真实产生的收益。
- 各学生按自己的固定验证答案选择最低验证交叉熵，包含第 0 轮，同分取最早。两者的训练更新次数相同，允许被选轮次不同；不看评测分数选轮次。
- 验收三条独立策略轨迹：纠错学生、自模仿学生、冻结原网络。全部使用各自网络对完整合法动作直接取 Q 最大值，推理时没有进张约束或 H0 接管。三种对手组合各 16 个完整配对组，每组包含六种座位、三版本、16 手连续对局，共 13,824 局；每个版本 4,608 手。
- 提升联合主张要求“纠错学生减原网络”和“纠错学生减自模仿学生”的双侧 95% 完整配对组 bootstrap 区间都严格大于零。属于交并检验：两个条件同时通过才支持整体主张，单项通过不替代另一项。按对手组合等权，5,000 次组重采样，不把组内的手数或座位当独立样本。
- 所有预算先写入 `plan.json`，不看中途分数扩样、调参或换模型。子组、固定验证决策吻合率均是描述性指标。共用纠错轨迹不是独立复验。本轮没有与“不亮倒 H0”直接做强度对照，不能据此宣布超过它。

## 审计与运行

采集器保存共同原始牌谱和两份对齐标签。审计重新按种子发牌，复算行为、两类教师、公开输入、全部动作、连续轮庄和结算，再验证合并数据与分片逐字节一致。三个版本评测全部重新运行匹配完整牌谱和分项分数。所有训练快照核对 PT 哈希、来源及轮次，验证 Python/JavaScript 导出误差、两个第 0 轮与原权重一致。

```powershell
node ai/outs-distill/study.mjs ai-runs/outs-distill-20261020 ai-runs/outs-guard-20261020
node ai/outs-distill/verify.mjs ai-runs/outs-distill-20261020
```

训练牌局按共同实际轨迹计一次，不能把两个学生共享的 4,608 手算成 9,216 手；验证另计。独立测试夹具不纳入正式累计。单个配对训练种子即使通过，仍须全新发牌复验与跨训练种子检验，才讨论晋级。
