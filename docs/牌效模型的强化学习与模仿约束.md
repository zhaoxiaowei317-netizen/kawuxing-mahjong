# 牌效模型的强化学习与模仿约束

上一轮动作牌效模型显著优于旧学习模型，但面对两家 H0 时仍落后。接下来的问题是：从这个基础判断更稳定的起点，用实际净得分训练，能否学到更好的取舍；加入 H0 模仿约束，是否能减少强化学习造成的基础能力退步。

本轮已完成，见[对照结果](reports/scorer-ppo-2026-10-18/实验结果.md)。按预设开发规则选回原牌效模型，未筛选出新的晋级候选；各训练终点、完整优化器和诊断结果均保留。

## 训练实现

`ai/action-scorer/rollout.mjs` 采集当前策略的随机动作，只把学习者自己的决策放入 PPO。默认 25% 对局为三席自博弈，其余由轮换座位的一席学习者对两席 H0。每局回报是实际结算净分除以 16，杠费、胡牌及流局费用各计一次，不另加人为牌效奖励。

`anchored.mjs` 在原有 PPO、熵与价值损失上加上 H0 标签的交叉熵，默认系数 0.2。H0 只看到与模型相同的公开观测和合法动作；老师标签仅进入训练损失，推理输入仍是原有 34 个动作特征和 10 个价值特征，没有增加暗牌、墙序或老师答案。

这次继承已有动作评分器的推理结构，旧模型可以继续加载。新训练代码单独记录版本和源码哈希。BC 约束与 PPO 梯度在同一批次相加，再共同裁剪、更新 Adam；没有额外多跑一遍老师训练。纯 PPO 的 BC 系数为 0。

每轮冻结采样时的动作概率与价值估计，使用完整单局蒙特卡洛回报，归一化优势，进行最多两遍更新。每遍之后计算相对采样策略的 KL 近似值，超过 0.03 则停止该轮后续遍数。这是限制后续更新的措施，不会回滚已经完成的一遍。每轮保存完整 Adam、计数、历史、父模型及训练参数。

## 固定对照设计

父模型为动作牌效同数据实验选中的第 0 个种子、第 12 遍模型。三个新的训练种子各分为纯 PPO、带模仿约束 PPO 两条路线，各 12 轮、每轮 128 局，合计新增 9,216 局。

两条路线复制同一父模型权重并重置 Adam，使用成对的发牌、座位及策略随机种子。学习率 0.002、批大小 128、最多两遍、熵系数 0.002、价值系数 0.1、全局梯度范数上限 0.5。只有模仿约束系数不同。策略分化会导致轨迹、学习决策数和 KL 提前停止次数不同，因此记录实际计数，不声称训练样本数完全相同。

先把原父模型和六个训练终点放到相同开发牌局：每对手组合 8 个单局组、1 个完整 16 局组，对手仍为 H0+H0、H0+速度策略，每组包含六种座位排列与两臂。先比较各路线跨三个种子的完整 16 局平均分差，父模型也参与；再取胜出路线中最好的种子。独立单局得分用于同分排序，完全相同则优先保留父模型。

候选冻结后，使用训练开始前生成并留下哈希承诺的新封存种子。与 H0、未改动的父模型各比较 32 个单局组和 8 个完整 16 局组。完整 16 局的两个配对分差区间下界均高于零，才支持本轮晋级。如果选回父模型，不重复评测自身对自身，也不把结果写成训练取得了提升。

主实验共 11,712 局评测；如果父模型胜出，则为 7,872 局。完整牌谱全部保存，分层审计样本现场重放。开发样本较小，只用于筛选；封存成绩不用于回头改选或调参。

## 执行整套对照

```powershell
node ai/action-scorer/rl-study.mjs --parent ai-runs/action-scorer-20261018/seed-0/structured-epoch-12.json --out ai-runs/scorer-ppo-new
```

可通过 `--config 配置.json` 覆盖实验默认参数，输出必须是新目录。`manifest.json` 保存预设方案，`events.jsonl` 和 `status.json` 保存进度；`seed-N/ppo`、`seed-N/anchored` 保存每轮检查点；`development.json`、`selection-frozen.json`、`sealed-vs-*/report.json` 保存评测证据。游戏默认 H0、规则和正式存档不随实验改变。

## 单独训练与恢复

创建一个训练配置 JSON，例如：

```json
{"seed":"my-scorer-run","handsPerIteration":128,"bcCoef":0.2}
```

```powershell
node ai/action-scorer/train.mjs --initialize-from ai-runs/action-scorer-20261018/seed-0/structured-epoch-12.json --config my-config.json --iterations 12 --out ai-runs/my-scorer-training
```

精确续训使用相同配置、Node 版本与训练源码，目标轮数须大于已有轮数，并写入新目录以保留原分支：

```powershell
node ai/action-scorer/train.mjs --resume ai-runs/my-scorer-training/checkpoints/iteration-00012.json --config my-config.json --iterations 24 --out ai-runs/my-scorer-continued
```

`--initialize-from` 复制权重、重置 Adam 和计数，用于新实验；`--resume` 恢复完整优化器和采样进度。两个参数互斥。整套对照入口不自动拼接中断的部分评测；已有文件保留，重跑使用新目录。

该线性模型仍主要表达牌效，尚未新增完整的对手听牌概率、放铳风险预测或长期收益网络。本轮主要验证训练方法能否在已有表示下取得额外收益；失败也可能反映学习步长、更新预算、表示或探索的限制，不能简单归结为强化学习对麻将无效。

本轮没有“只继续模仿、不使用收益训练”的第三条训练路线。如果组合方案获益，只能归因于整套组合，不能据此断言 PPO 本身贡献了提升；要拆解来源，需要另行预设继续模仿的对照。
