# 模型自身局面纠错实验

这是首轮三路线对照之外的一个有界补充实验。原对照的预算、筛选与封存流程没有改变。

本轮已完成，详见[纠错实验结果](reports/teacher-refine-2026-10-17/实验结果.md)。随后又从纠错模型出发做了固定 12 轮 PPO 和全新牌局验收，完整对比见[总报告](reports/research-2026-10-18/本轮结果与下一步.md)。

## 触发原因

对第 0 个训练种子的模仿模型做了两种状态分布诊断，每种 160 局：H0 驱动的对局中，模型与 H0 在非强制动作上的一致率约 48.09%；换成模型自己驱动的对局，一致率约 39.55%。选择更高向听数的出牌比例分别约 15.48% 与 22.16%，碰/过分歧也较大。

更高向听数有时是做大牌或防守的合理取舍，不能单凭这个指标宣布动作错误。这里把它作为牌效诊断，与完整对局净分一起判断。诊断原始数据在 `ai-runs/controlled-20261017/diagnostics/seed-0-imitation.json`。

## 实验方法

从上述模仿模型复制权重、重置 Adam，执行三轮，每轮 800 局、4 遍交叉熵训练，学习率 0.0005，批大小 128。

每轮一半对局由 H0 驱动，一半由当前冻结模型按最大概率动作驱动。所有学习标签都由 H0 基于当前行动玩家可见的信息生成；模型驱动的轨迹继续执行模型自己的动作，不能把老师建议的动作伪称为实际执行动作。每轮重新采集数据，上一轮权重继续训练；当前实现不保留全部历史样本池。

两种固定验证分布分别是 120 局 H0 驱动和 120 局原始父模型驱动的独立牌局，均使用 H0 标注。原始父模型驱动的验证集在后续各轮保持不变，避免验证样本跟着模型漂移。用两种分布平均交叉熵选模型，父模型也可被选中；验证数据不加入梯度更新。

候选固定后，再对 H0 和原始模仿父模型做独立验收：每个对手组合 16 个单局组、4 个完整 16 局组，六座位排列、候选/基线两臂。封存种子在训练前生成并记录哈希，牌局只在选定模型后生成。每份评测分层重放 48 局。

这是一项**单种子、增加额外数据的探索实验**，不能区分收益究竟来自更多数据还是来自模型自身局面标注，也不能证明跨训练种子的稳定性。无论结果如何，都不改游戏默认 AI。看过的验收批次不再用于下一轮独立认证。

## 运行与复核

```powershell
node ai/teacher-refine.mjs --parent ai-runs/controlled-20261017/seed-0/imitation-epoch-8.json --out ai-runs/teacher-refine-001
```

原父模型必须仍兼容当前推理代码。输出目录须为新目录。训练配置、源文件哈希、父模型哈希写入 `manifest.json`；每轮保存 `round-N.json`、`history.json`，进度写入 `status.json` 和 `events.jsonl`，完成后生成 `summary.json`、`sealed-vs-H0.json` 和 `sealed-vs-parent.json`。快照可用于推理或新实验初始化，不冒充完整 PPO 精确续训检查点。

可以对任意兼容模型重复动作诊断，使用新的输出文件：

```powershell
node ai/analyze-model.mjs --model PATH_TO_CHECKPOINT --episodes 160 --out ai-runs/diagnostic-001.json
```

诊断只读取玩家可见信息，不提供真实暗手或牌墙。示例牌例包含当时自己手牌、公开副露、所选动作和老师动作，便于人工复查。
