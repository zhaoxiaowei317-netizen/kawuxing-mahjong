# 牌面模型独立复验

上一轮的离线收益模型在预定的新种子连续对局主指标上领先 H0，但只有一个配对训练种子，独立单局和混合对手子组也未确认优势。本轮先检验该发现能否重现，不增加网络结构、修改配方或根据测试结果挑选模型。

## 两项不同的问题

1. **旧模型复验（唯一主要检验）**：冻结 `tile-q-20261018` 的 `tiles-offline` 所选快照，用全新种子与 H0 对照。16 手连续对局的净底分差及其 95% 配对组区间是主要指标；仅当整个区间高于零，才称这次复验得到正收益证据。
2. **训练流程重复（次要描述）**：使用新训练、验证、初始化种子，按固定的牌面模仿→离线收益学习配方重训。新模型也完成同样的测试，帮助判断上一轮成果是否依赖特定训练数据或初始化。它同时改变这三类种子，不是单独的初始化消融。

两版模型分别测试，不根据测试结果重新选快照或调参数。第二项、独立单局、各对手子组均为次要描述，没有作多重比较校正，不能把其中偶然最好的一个改称主要发现。总计两个训练运行也不足以证明训练方法具有稳定性。

## 正式固定预算

新训练用 2,400 手、固定验证用 480 手，按 16 手连续环境采集。牌面模仿最多 12 轮，离线收益学习最多 8 轮，包含第 0 轮；按各自的固定验证组合损失选取快照，打平保留较早轮次。沿用上一轮网络、学习率和损失权重，不继续生成在线训练数据。

每版模型分别完成：

- 独立单局：每种对手组合 64 个种子组。
- 连续对局：每种对手组合 16 个种子组，每组 16 手。
- 两种组合：H0/H0、H0/greedy-speed。
- 每组使用六种座位排列，每个排列分别执行候选和 H0 两条对照轨迹。

每版实际运行 `24 × (64 + 16 × 16) = 7,680` 局，两版合计 15,360 局。连续主指标每版有 32 个配对组、3,072 手候选和同数 H0 对照；辅助单局每版有 128 个配对组、768 手候选和同数对照。

两版使用同一套新测试种子，便于对照；因此其 H0 轨迹应完全相同。实际重复执行的牌局计入计算工作量，但不会因此增加独立起手数量。对手组合等权、完整配对种子组重采样，5,000 次 bootstrap。整组内的座位和连续牌局不能当成互相独立的样本。

## 运行与复核

```powershell
node ai/tile-q/replicate.mjs ai-runs/tile-q-confirm-20261019 ai-runs/tile-q-20261018
node ai/tile-q/replicate.mjs verify ai-runs/tile-q-confirm-20261019
node --test tests/ai-tile-q-replication.test.mjs
```

计划必须在第一手新牌之前写入，记录旧快照、旧结果、核心源码与复验驱动的哈希，以及全部新种子、预算、主要和次要指标。输出目录已存在时拒绝覆盖。本轮不自动修改游戏默认 H0。

训练和评测仍调用上一轮冻结的实现。审计重新发牌，逐步核对双方策略动作、训练公开编码、教师标签、收益、轮庄和统计；另核对模型与 Adam 存档的哈希、Python/JavaScript 数值一致性以及验证选轮规则。小规模集成测试还比较两版 H0 对照的完整组记录是否相同。

复验结束按固定预算报告全部结果，不追加牌局试图让区间转正，不把此次测试用于训练。若旧模型未重现优势，应降低对前次结果的信心；若新训练也未重现，下一阶段应查明数据覆盖与训练稳定性，而不是直接增加在线训练轮数。
