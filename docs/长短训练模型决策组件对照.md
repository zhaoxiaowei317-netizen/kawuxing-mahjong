# 长短训练模型决策组件对照

日期：2026-10-22，版本 `kwx-decision-components-1`。上轮长版（验证所选第 26 轮）相对短版（第 8 轮）为 -7.90 底分/百手，95% 区间 [-17.47, 1.58]。点估计偏负但区间跨零，不能预设长版一定退步或某类动作一定造成损失。

本轮只检验冻结策略组件，不新增训练、验证或优化更新。不使用旧验收牌谱训练，也不改模型权重。游戏默认 H0。

## 五种预定策略

按“动作控制器 / 亮倒标志 / 弃牌牌张”三层组合。同一公开输入与完整合法动作掩码，先计算所需冻结网络的 Q；同分取动作 ID 最小者。所有层只在已有合法候选中选择，不重新计算受限掩码的 Q。

1. 动作控制器取自身全合法 Q 最大动作；如果不是弃牌，直接采用该动作，包括是否胡、碰、杠、过及杠牌选择。
2. 如果控制器选择弃牌，亮倒层在所有合法弃牌中取自身 Q 最大者的亮倒标志；只有一种合法标志时直接采用该标志。
3. 弃牌层在该合法标志下，取自身 Q 最大牌张。因此改变亮倒时，合法牌张集合可能随之变化，实际牌张也可能变化；不声称这是保持牌张的纯亮倒实验。

| 策略 | 控制器 | 亮倒层 | 牌张层 |
| --- | --- | --- | --- |
| short | 短版 | 短版 | 短版 |
| long | 长版 | 长版 | 长版 |
| tile | 短版 | 短版 | 长版 |
| reveal | 短版 | 长版 | 短版 |
| other | 长版 | 短版 | 短版 |

同源的三个层必须精确重现原网络直接选择，包含胡、碰杠、亮倒和同分次序。混合版不回退 H0，不另加进张规则或手工分数阈值。

## 预定预算和统计

三种原有对手组合各 16 个完整组，每组六种座位、五条策略轨迹、真实连续轮庄 16 手，共 **23,040 局**，每策略 4,608 手。全新种子在首局前写入计划。共享起始牌墙，各策略轨迹独立；按完整组抽样，不能把座位、版本或各手当独立样本。

三个主要对照为 tile、reveal、other 各减 short。对手组合等权，组内配对，bootstrap 5,000 次，共用每次各组合内的组索引。采用 Bonferroni 校正：每项双侧 **98.333333%** 百分位区间，三项检验族 alpha 0.05。区间严格正为正收益证据，严格负为负收益证据，否则不确定。普通 95% 区间、子组与行为统计均为未经多重比较校正的描述，不能替代主要区间。

long 减 short 为同期描述，用于观察上轮现象在新批次的表现，不与旧批相减或事后合并争取显著性。本轮没有不亮倒 H0 的目标轨迹，因此不能声称超过强参照、晋级或发现通用冠军。

这是在另外两层固定为短版时，替换单个组件的策略干预。没有跑完整 2³ 因子组合，不估计组件交互，也不能把三个差值相加解释整个 long-short 分差。改变早期动作会改变后续局面，分数是完整策略的后果，不是每次决策的独立价值标签。

## 执行和核验

冻结源码、模型、预算与统计方式后，全部完成，无中途换模型、调阈值、追加预算或自动挑选最好的混合版。最多 2,048 项精确公开编码缓存只用于减少重复 Q 计算；键包含完整合法 ID 和全部公开编码，不使用真实暗手、牌墙或种子。缓存以完整键相等判断，不用近似匹配。

审计关闭缓存，从种子重新运行全部 23,040 局，核对逐动作轨迹、组件计数、连续轮庄、分项结算和统计区间。测试另核对双亲重现、单组件语义、受限合法候选、同分次序、缓存开关一致性、不可见信息不影响缓存，以及错误牌谱/汇总被拒绝。
