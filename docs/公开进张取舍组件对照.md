# 公开进张取舍的固定组件对照

上一轮固定收益模型相对不亮倒 H0 为 -10.89 底分/百手，95% 区间 [-19.40, -1.93]，未通过晋级。事后复放 288 局中，两者都弃牌的 2,228 次选择，弃牌后向听完全相同，但模型有 259 次公开进张更少，更多的仅 2 次。这只是待检验线索，不足以认定那些动作错误或造成了输分。

## 唯一固定干预

沿用原 offline 第 8 轮权重（JSON SHA-256 `e9374f999a3481c109a9605f3a59e1c18c5682cb6187ea38ece7105c917cac82`）。先按完整合法动作掩码计算原网络 Q，并确定原动作：

1. 原动作不是弃牌时，执行原动作。
2. 原动作是弃牌时，保留它的亮倒开关与弃牌后向听数，只比较同一亮倒开关、同一向听数的合法弃牌。
3. 在这些牌里优先选择公开进张最多的弃牌，再按原完整掩码的 Q 分数排序；精确平分沿用原动作编号顺序。

若原动作已经达到该条件下的最大公开进张，执行原动作。没有调用 H0 代打，不改变胡/碰/杠/过，也没有重算受限掩码的 Q。动作、亮倒与向听的约束只在相同公开局面逐点成立，未来牌局轨迹仍会因不同弃牌而改变。

公开进张使用原候选特征：根据公开可见张数估计改善向听的未公开牌张数，**不是真实牌墙中剩余张数**。不按番数或阶段另设阈值，不搜索多个版本，不新增神经网络训练。

## 三条轨迹、一个主要检验

三种对手组合固定等权：不亮倒/H0、不亮倒/不亮倒、不亮倒/速度贪心。每组合 16 个全新种子组，每组包含六种座位、连续 16 手和三条完整轨迹：约束版、原网络、不亮倒 H0。保留真实连续轮庄和累计分。

总计 **13,824 局实际评测**，48 个完整组，每种目标策略各 4,608 手。两个对照共用同一条约束版轨迹，不能把它当成两份独立证据，也不重复计数。

- **唯一主要检验：约束版减原网络。** 95% 双侧配对组区间完全大于零，才称本批支持这个固定组件带来正收益。
- **次要描述：约束版减不亮倒 H0。** 与全部对手子组、行为统计一样，未经多重比较校正；即使为正，也不直接宣称跨对手稳定超过强参照，需要独立复验。
- 组合等权，整组 bootstrap 5,000 次。不把同组座位/手数或共享轨迹当作独立样本。
- 第一局之前固定全部计划、来源、源码与模型哈希和新种子。预算全部跑完，不据中途结果追加、缩减、改模型或改约束。旧批次不合并用于显著性声明。

无论结果如何，默认电脑保持 H0。若约束有效，这是冻结网络上增加策略组件的证据，不等于网络已自主学会进张取舍。之后才决定是否蒸馏、增加辅助目标或改采样；规则组件与训练收益需分别验证。
